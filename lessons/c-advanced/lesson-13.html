Bài 13: Double Pointer & Multiple-level Pointer

Trong ngôn ngữ C, Pointer không chỉ được sử dụng để lưu địa chỉ của các biến thông thường. Một Pointer cũng có thể lưu địa chỉ của một Pointer khác.

Khi một Pointer trỏ đến một Pointer khác, chúng ta có khái niệm Double Pointer. Tương tự, C còn hỗ trợ các cấp Pointer sâu hơn như Triple Pointer hoặc Multiple-level Pointer.

Những kỹ thuật này giúp chương trình có thể truy cập dữ liệu qua nhiều cấp địa chỉ, thay đổi giá trị Pointer từ bên trong Function và tổ chức các cấu trúc dữ liệu phức tạp hơn.

Trong bài học này, chúng ta sẽ tập trung vào Double Pointer, Multiple-level Pointer, cách Dereference từng cấp và cách truyền địa chỉ Pointer vào Function. Các kỹ thuật Function Pointer và Callback Function sẽ được trình bày riêng trong Bài 14.

1. Tổng quan về Double Pointer

1.1. Double Pointer là gì?

Double Pointer là một Pointer lưu địa chỉ của một Pointer khác.

Với một biến thông thường, chúng ta có thể khai báo Pointer để lưu địa chỉ của biến đó: 

int value = 10;

int *ptr = &value;

Trong ví dụ trên, ptr lưu địa chỉ của biến value. Khi sử dụng toán tử Dereference *ptr, chương trình có thể truy cập giá trị được lưu tại địa chỉ đó.

Nếu muốn lưu địa chỉ của chính Pointer ptr, chúng ta có thể khai báo thêm một cấp Pointer: 

int **pptr = &ptr;

Trong đó:

  • value: Biến kiểu int.
  • ptr: Pointer kiểu int *, trỏ đến value.
  • pptr: Double Pointer kiểu int **, trỏ đến ptr.

1.2. Cú pháp khai báo Double Pointer

Cú pháp tổng quát:

data_type **pointer_name;

Ví dụ:

int **pptr;
char **char_pptr;
uint8_t **buffer_pptr;

Ý nghĩa:

  • int **pptr: Pointer trỏ đến một Pointer kiểu int *.
  • char **char_pptr: Pointer trỏ đến một Pointer kiểu char *.
  • uint8_t **buffer_pptr: Pointer trỏ đến một Pointer kiểu uint8_t *.

Số lượng dấu * trong khai báo thể hiện số cấp Pointer trong kiểu dữ liệu.

1.3. So sánh Single Pointer và Double Pointer

Đặc điểm Single Pointer Double Pointer
Khai báo int *ptr int **pptr
Đối tượng được trỏ đến Một biến int Một Pointer kiểu int *
Dereference *ptr *pptr và **pptr
Giá trị có thể truy cập Giá trị của biến int Địa chỉ Pointer và giá trị int ở cấp tiếp theo
Điểm cần nhớ: Double Pointer không trực tiếp trỏ đến một biến int. Nó trỏ đến một Pointer kiểu int *. Muốn truy cập giá trị int cuối cùng, cần Dereference qua hai cấp.

2. Cách hoạt động của Double Pointer

2.1. Ví dụ cơ bản

Hãy xét chương trình sau để quan sát mối quan hệ giữa biến, Single Pointer và Double Pointer. 

#include <stdio.h>

int main(void)
{
    int value = 100;

    int *ptr = &value;
    int **pptr = &ptr;

    printf("Value: %d\n", value);

    printf("Value through ptr: %d\n", *ptr);

    printf("Value through pptr: %d\n", **pptr);

    return 0;
}

Kết quả:

Value: 100
Value through ptr: 100
Value through pptr: 100

Giải thích:

  • value chứa giá trị 100.
  • ptr = &value khiến ptr lưu địa chỉ của value.
  • pptr = &ptr khiến pptr lưu địa chỉ của ptr.
  • *ptr truy cập giá trị của value.
  • **pptr Dereference hai lần để truy cập giá trị của value.

2.2. Minh họa mối quan hệ giữa các Pointer

Có thể hình dung cách tổ chức dữ liệu trong ví dụ trên như sau: 

       pptr
        |
        | stores address of ptr
        v
     +--------+
     |  ptr   |
     +--------+
        |
        | stores address of value
        v
     +--------+
     | value  |
     +--------+
     |  100   |
     +--------+

Cần phân biệt giữa địa chỉ được lưu trong Pointer và giá trị mà Pointer truy cập được sau khi Dereference.

Biểu thức Ý nghĩa
pptr Địa chỉ của Pointer ptr.
*pptr Giá trị Pointer ptr, tức địa chỉ của value.
**pptr Giá trị của biến value.

2.3. Địa chỉ và giá trị qua từng cấp Pointer

Chúng ta có thể sử dụng toán tử & và * để quan sát mối quan hệ giữa các cấp Pointer. 

#include <stdio.h>

int main(void)
{
    int value = 50;

    int *ptr = &value;
    int **pptr = &ptr;

    printf("Address of value: %p\n", (void *)&value);
    printf("Value stored in ptr: %p\n", (void *)ptr);

    printf("Address of ptr: %p\n", (void *)&ptr);
    printf("Value stored in pptr: %p\n", (void *)pptr);

    printf("Value through **pptr: %d\n", **pptr);

    return 0;
}

Trong chương trình này:

  • &value là địa chỉ của biến value.
  • ptr lưu địa chỉ của value.
  • &ptr là địa chỉ của biến Pointer ptr.
  • pptr lưu địa chỉ của ptr.
  • **pptr truy cập giá trị cuối cùng là 50.
Lưu ý: Địa chỉ thực tế hiển thị bởi %p phụ thuộc vào hệ thống và lần chạy chương trình. Không nên giả định địa chỉ của các biến sẽ có một giá trị cố định.

3. Dereference qua nhiều cấp Pointer

3.1. Ý nghĩa của từng cấp Dereference

Khi làm việc với Double Pointer, mỗi lần sử dụng toán tử Dereference * sẽ truy cập thêm một cấp. 

int value = 25;

int *ptr = &value;
int **pptr = &ptr;

Có thể phân tích như sau:

Biểu thức Kiểu dữ liệu Ý nghĩa
pptr int ** Pointer đến một Pointer int.
*pptr int * Pointer đến biến int.
**pptr int Giá trị của biến int.

3.2. Thay đổi giá trị thông qua Double Pointer

Double Pointer không chỉ cho phép đọc dữ liệu mà còn có thể thay đổi giá trị của biến được trỏ đến thông qua nhiều cấp. 

#include <stdio.h>

int main(void)
{
    int value = 10;

    int *ptr = &value;
    int **pptr = &ptr;

    **pptr = 200;

    printf("Value: %d\n", value);

    return 0;
}

Kết quả:

Value: 200

Giải thích:

  • pptr trỏ đến ptr.
  • *pptr truy cập Pointer ptr.
  • **pptr truy cập biến value.
  • Phép gán **pptr = 200 thay đổi giá trị của value.

3.3. Thay đổi địa chỉ Pointer thông qua Double Pointer

Một điểm quan trọng của Double Pointer là nó có thể được sử dụng để thay đổi giá trị địa chỉ mà một Single Pointer đang lưu. 

#include <stdio.h>

int main(void)
{
    int value1 = 10;
    int value2 = 20;

    int *ptr = &value1;
    int **pptr = &ptr;

    printf("Before: %d\n", **pptr);

    *pptr = &value2;

    printf("After: %d\n", **pptr);

    return 0;
}

Kết quả:

Before: 10
After: 20

Giải thích:

  • Ban đầu, ptr lưu địa chỉ của value1.
  • pptr lưu địa chỉ của Pointer ptr.
  • *pptr = &value2 thay đổi giá trị của ptr.
  • Sau phép gán, ptr trỏ đến value2.
  • Do đó, **pptr truy cập được giá trị 20.
Phân biệt hai thao tác: **pptr = 200 thay đổi giá trị của biến mà Pointer cuối cùng trỏ đến. Trong khi đó, *pptr = &value2 thay đổi địa chỉ mà Single Pointer đang lưu.

4. Multiple-level Pointer

4.1. Multiple-level Pointer là gì?

Ngoài Double Pointer, C còn cho phép khai báo Pointer có nhiều hơn hai cấp. Những Pointer này thường được gọi chung là Multiple-level Pointer.

Ví dụ:

int *ptr;
int **pptr;
int ***ppptr;
int ****pppptr;

Các khai báo trên lần lượt biểu diễn:

  • int *ptr: Pointer đến biến kiểu int.
  • int **pptr: Pointer đến Pointer kiểu int.
  • int ***ppptr: Pointer đến Double Pointer kiểu int.
  • int ****pppptr: Pointer đến Triple Pointer kiểu int.

4.2. Ví dụ về Triple Pointer

Triple Pointer có ba cấp Pointer. Để truy cập giá trị của biến int ban đầu, cần Dereference ba lần. 

#include <stdio.h>

int main(void)
{
    int value = 123;

    int *ptr = &value;
    int **pptr = &ptr;
    int ***ppptr = &pptr;

    printf("Value: %d\n", ***ppptr);

    return 0;
}

Kết quả:

Value: 123

Có thể hình dung mối quan hệ như sau: 

ppptr
  |
  v
+-------+
| pptr  |
+-------+
  |
  v
+-------+
| ptr   |
+-------+
  |
  v
+-------+
| value |
+-------+
|  123  |
+-------+

Mỗi cấp Pointer lưu địa chỉ của Pointer ở cấp tiếp theo. Khi sử dụng ba toán tử Dereference, chương trình truy cập đến giá trị của biến ban đầu.

4.3. So sánh các cấp Pointer

Khai báo Số cấp Cách truy cập giá trị int
int *ptr 1 *ptr
int **pptr 2 **pptr
int ***ppptr 3 ***ppptr
int ****pppptr 4 ****pppptr

Về mặt cú pháp, C cho phép khai báo nhiều cấp Pointer. Tuy nhiên, trong chương trình thực tế, không nên tăng số cấp Pointer nếu không có nhu cầu rõ ràng vì điều này có thể khiến mã nguồn khó đọc, khó kiểm tra và khó bảo trì.

5. Truyền Double Pointer vào Function

5.1. Vấn đề khi truyền Single Pointer vào Function

Trong C, tham số của Function được truyền theo cơ chế Pass by Value. Điều này có nghĩa Function nhận một bản sao giá trị của tham số.

Khi truyền một Single Pointer vào Function, Function nhận bản sao địa chỉ của Pointer. Vì vậy, nếu Function thay đổi giá trị Pointer đó, Pointer ban đầu ở Function gọi sẽ không tự động thay đổi. 

#include <stdio.h>

void ChangePointer(int *ptr)
{
    int new_value = 100;

    ptr = &new_value;
}

int main(void)
{
    int value = 10;
    int *ptr = &value;

    ChangePointer(ptr);

    printf("Value: %d\n", *ptr);

    return 0;
}

Kết quả:

Value: 10

Giải thích:

  • ptr trong main() trỏ đến biến value.
  • Khi gọi ChangePointer(ptr), Function nhận một bản sao của địa chỉ.
  • Phép gán ptr = &new_value chỉ thay đổi bản sao Pointer bên trong Function.
  • Pointer trong main() vẫn trỏ đến value.
Trong ví dụ trên, new_value là biến local. Không được trả về hoặc lưu lại địa chỉ của biến này để sử dụng sau khi Function kết thúc vì Lifetime của biến đã kết thúc.

5.2. Sử dụng Double Pointer để thay đổi Pointer từ Function

Nếu muốn Function thay đổi địa chỉ mà Pointer ở Function gọi đang lưu, chúng ta có thể truyền địa chỉ của Pointer đó.

Vì địa chỉ của một Single Pointer có kiểu Double Pointer, tham số Function cần được khai báo với hai dấu *. 

#include <stdio.h>

void ChangePointer(int **pptr, int *new_address)
{
    *pptr = new_address;
}

int main(void)
{
    int value1 = 10;
    int value2 = 50;

    int *ptr = &value1;

    printf("Before: %d\n", *ptr);

    ChangePointer(&ptr, &value2);

    printf("After: %d\n", *ptr);

    return 0;
}

Kết quả:

Before: 10
After: 50

Giải thích:

  • &ptr là địa chỉ của Pointer ptr.
  • Địa chỉ này được truyền vào tham số pptr.
  • *pptr đại diện cho Pointer ptr ở Function gọi.
  • *pptr = new_address thay đổi địa chỉ mà ptr đang lưu.
  • Sau khi Function kết thúc, ptr trong main() trỏ đến value2.

5.3. Sử dụng Double Pointer làm Output Parameter

Một ứng dụng phổ biến khác của Double Pointer là cho phép Function trả về một Pointer thông qua tham số.

Trong C, Function chỉ có thể trả về một giá trị trực tiếp thông qua câu lệnh return. Khi cần trả về thêm thông tin hoặc địa chỉ của một vùng dữ liệu, có thể sử dụng Output Parameter. 

#include <stdio.h>
#include <stdint.h>

static uint8_t rx_buffer[8] = {
    0x10U, 0x20U, 0x30U, 0x40U,
    0x50U, 0x60U, 0x70U, 0x80U
};

int GetRxBuffer(uint8_t **buffer, uint32_t *length)
{
    if ((buffer == NULL) || (length == NULL)) {
        return -1;
    }

    *buffer = rx_buffer;
    *length = sizeof(rx_buffer);

    return 0;
}

int main(void)
{
    uint8_t *data = NULL;
    uint32_t data_length = 0U;

    if (GetRxBuffer(&data, &data_length) == 0) {
        printf("Buffer length: %lu\n",
               (unsigned long)data_length);

        for (uint32_t i = 0U; i < data_length; i++) {
            printf("%02X ", (unsigned int)data[i]);
        }

        printf("\n");
    }

    return 0;
}

Kết quả:

Buffer length: 8
10 20 30 40 50 60 70 80

Giải thích:

  • rx_buffer là một Buffer có phạm vi tồn tại trong toàn bộ chương trình.
  • data là Pointer được khai báo trong main().
  • &data là địa chỉ của Pointer data, có kiểu uint8_t **.
  • Function nhận địa chỉ này thông qua tham số buffer.
  • *buffer = rx_buffer gán địa chỉ Buffer cho Pointer data ở Function gọi.
  • length được sử dụng để trả về kích thước Buffer.
Ứng dụng: Double Pointer thường xuất hiện trong API C khi một Function cần cung cấp địa chỉ Buffer, cập nhật Pointer hoặc trả về một vùng dữ liệu cho Function gọi. Cần đảm bảo vùng dữ liệu được trả về vẫn còn hợp lệ trong thời gian Function gọi sử dụng nó.

6. Mối quan hệ giữa Double Pointer và Array of Pointers

6.1. Array of Pointers

Trong Bài 12, chúng ta đã tìm hiểu về Array of Pointers. Đây là một Array mà mỗi phần tử là một Pointer. 

int value1 = 10;
int value2 = 20;

int *ptr_array[2] = {
    &value1,
    &value2
};

Trong trường hợp này:

  • ptr_array là một Array gồm hai phần tử.
  • ptr_array[0] là Pointer đến value1.
  • ptr_array[1] là Pointer đến value2.

6.2. Double Pointer trỏ đến phần tử đầu tiên của Array of Pointers

Chúng ta có thể sử dụng Double Pointer để trỏ đến phần tử đầu tiên của Array of Pointers. 

#include <stdio.h>

int main(void)
{
    int value1 = 10;
    int value2 = 20;
    int value3 = 30;

    int *ptr_array[3] = {
        &value1,
        &value2,
        &value3
    };

    int **pptr = ptr_array;

    for (int i = 0; i < 3; i++) {
        printf("Value %d: %d\n", i, *pptr[i]);
    }

    return 0;
}

Kết quả:

Value 0: 10
Value 1: 20
Value 2: 30

Giải thích:

  • ptr_array là Array gồm ba Pointer kiểu int *.
  • Trong biểu thức gán này, ptr_array được chuyển đổi thành Pointer đến phần tử đầu tiên.
  • pptr có kiểu int **.
  • pptr[i] truy cập Pointer thứ i trong Array.
  • *pptr[i] truy cập giá trị int mà Pointer đó trỏ đến.

6.3. Double Pointer không đồng nghĩa với Array of Pointers

Mặc dù Double Pointer có thể trỏ đến phần tử đầu tiên của Array of Pointers, hai khái niệm này không giống nhau. 

int *ptr_array[3];

int **pptr;
Đặc điểm Array of Pointers Double Pointer
Khai báo int *ptr_array[3] int **pptr
Bản chất Array gồm 3 Pointer Một Pointer đến Pointer int
Kích thước Kích thước của 3 Pointer Kích thước của một Pointer
Khả năng lưu địa chỉ Lưu 3 địa chỉ Pointer Lưu địa chỉ của một Pointer
Điểm quan trọng: Array of Pointers là một Array, còn Double Pointer là một Pointer. Việc một Double Pointer có thể trỏ đến phần tử đầu tiên của Array of Pointers không làm thay đổi bản chất kiểu dữ liệu của hai đối tượng này.

7. Double Pointer với dữ liệu nhiều chiều

7.1. Double Pointer không tương đương với Pointer to 2D Array

Một trong những nhầm lẫn thường gặp khi học Double Pointer là cho rằng một Array hai chiều có thể được thay thế trực tiếp bằng một Double Pointer.

Hãy xét hai khai báo:

int matrix[2][3];

int **pptr;

Hai khai báo này có bản chất khác nhau:

  • matrix là một Array hai chiều gồm 2 hàng và 3 cột.
  • pptr là một Pointer trỏ đến một Pointer kiểu int.
  • Kiểu Pointer khi Array hai chiều chuyển đổi trong biểu thức thông thường là int (*)[3].
  • Double Pointer có kiểu int **, không phải int (*)[3].

Vì vậy, không thể thực hiện phép gán sau: 

int matrix[2][3];

int **pptr = matrix; /* Không tương thích kiểu */

Nguyên nhân là matrix chuyển đổi thành Pointer đến một Array gồm 3 phần tử int, trong khi pptr yêu cầu địa chỉ của một Pointer kiểu int.

7.2. Sử dụng Double Pointer với các hàng dữ liệu riêng biệt

Nếu muốn sử dụng Double Pointer để truy cập nhiều nhóm dữ liệu, chúng ta có thể tổ chức mỗi hàng thành một Array riêng biệt và sử dụng một Array of Pointers để lưu địa chỉ của các hàng. 

#include <stdio.h>

int main(void)
{
    int row1[3] = {10, 20, 30};
    int row2[3] = {40, 50, 60};

    int *rows[2] = {
        row1,
        row2
    };

    int **pptr = rows;

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", pptr[i][j]);
        }

        printf("\n");
    }

    return 0;
}

Kết quả:

10 20 30
40 50 60

Trong ví dụ này, Double Pointer có thể truy cập các hàng thông qua Array of Pointers.

Cách tổ chức này khác với một Array hai chiều thông thường:

  • Các hàng row1 và row2 là những Array độc lập.
  • Array rows lưu địa chỉ bắt đầu của từng hàng.
  • pptr trỏ đến phần tử đầu tiên của Array rows.
  • Các vùng dữ liệu được trỏ đến không bắt buộc phải nằm liên tiếp trong bộ nhớ.
Double Pointer thường được sử dụng với các cấu trúc dữ liệu có nhiều vùng dữ liệu độc lập. Tuy nhiên, khi làm việc với Array hai chiều có kích thước cố định, Pointer to Array thường là cách biểu diễn kiểu dữ liệu phù hợp hơn.

8. Ứng dụng của Double Pointer trong Embedded C

8.1. Quản lý địa chỉ Buffer

Trong Embedded Systems, một Function có thể cần cập nhật địa chỉ Buffer mà một Module đang sử dụng.

Ví dụ, một Function có thể lựa chọn Buffer phù hợp dựa trên trạng thái xử lý và trả lại địa chỉ cho Function gọi. 

#include <stdint.h>
#include <stdio.h>

#define BUFFER_SIZE    8U

static uint8_t rx_buffer[BUFFER_SIZE] = {
    0x10U, 0x20U, 0x30U, 0x40U,
    0x50U, 0x60U, 0x70U, 0x80U
};

static uint8_t tx_buffer[BUFFER_SIZE] = {
    0xA0U, 0xA1U, 0xA2U, 0xA3U,
    0xA4U, 0xA5U, 0xA6U, 0xA7U
};

int SelectBuffer(uint8_t **selected_buffer,
                 uint8_t is_transmit)
{
    if (selected_buffer == NULL) {
        return -1;
    }

    if (is_transmit != 0U) {
        *selected_buffer = tx_buffer;
    } else {
        *selected_buffer = rx_buffer;
    }

    return 0;
}

int main(void)
{
    uint8_t *active_buffer = NULL;

    if (SelectBuffer(&active_buffer, 1U) == 0) {
        printf("Selected TX Buffer:\n");

        for (uint32_t i = 0U; i < BUFFER_SIZE; i++) {
            printf("%02X ", (unsigned int)active_buffer[i]);
        }

        printf("\n");
    }

    return 0;
}

Kết quả:

Selected TX Buffer:
A0 A1 A2 A3 A4 A5 A6 A7

Trong ví dụ này:

  • rx_buffer và tx_buffer là hai Buffer riêng biệt.
  • active_buffer lưu địa chỉ Buffer đang được lựa chọn.
  • &active_buffer được truyền vào Function dưới dạng Double Pointer.
  • Function sử dụng *selected_buffer để cập nhật địa chỉ của active_buffer.

8.2. Trả về Buffer từ một Module

Trong một chương trình Embedded được chia thành nhiều Module, một Module có thể cung cấp API để Module khác lấy địa chỉ của Buffer đang được quản lý.

Ví dụ: 

#include <stdint.h>
#include <stddef.h>

#define CAN_DATA_SIZE    8U

static uint8_t can_rx_data[CAN_DATA_SIZE];

int CAN_GetRxData(uint8_t **data,
                  uint32_t *length)
{
    if ((data == NULL) || (length == NULL)) {
        return -1;
    }

    *data = can_rx_data;
    *length = CAN_DATA_SIZE;

    return 0;
}

Module gọi API có thể nhận được địa chỉ Buffer thông qua tham số Double Pointer: 

uint8_t *received_data = NULL;
uint32_t received_length = 0U;

if (CAN_GetRxData(&received_data,
                  &received_length) == 0) {
    /* Process received CAN data */
}

Cách thiết kế này giúp Module quản lý Buffer giữ quyền kiểm soát vùng dữ liệu, trong khi Module khác có thể nhận địa chỉ để đọc hoặc xử lý dữ liệu theo API được cung cấp.

Lưu ý trong Embedded: Việc trả về địa chỉ Buffer không có nghĩa Module gọi được quyền sở hữu hoặc tự do thay đổi toàn bộ vùng dữ liệu. Cần xác định rõ quyền đọc/ghi, thời gian hợp lệ của Buffer và cơ chế đồng bộ nếu Buffer được chia sẻ giữa nhiều Execution Context.

8.3. Quản lý trạng thái Pointer trong các Module

Double Pointer cũng có thể được sử dụng khi một Function cần cập nhật trạng thái Pointer của Module khác.

Ví dụ, một Function có thể cập nhật Pointer hiện tại để chuyển sang một vùng dữ liệu khác sau khi hoàn thành một bước xử lý. 

#include <stdint.h>
#include <stdio.h>

static uint8_t buffer_a[4] = {
    1U, 2U, 3U, 4U
};

static uint8_t buffer_b[4] = {
    5U, 6U, 7U, 8U
};

void SwitchBuffer(uint8_t **current_buffer,
                  uint8_t select_b)
{
    if (current_buffer == NULL) {
        return;
    }

    if (select_b != 0U) {
        *current_buffer = buffer_b;
    } else {
        *current_buffer = buffer_a;
    }
}

int main(void)
{
    uint8_t *current_buffer = buffer_a;

    printf("Before: %u\n",
           (unsigned int)current_buffer[0]);

    SwitchBuffer(&current_buffer, 1U);

    printf("After: %u\n",
           (unsigned int)current_buffer[0]);

    return 0;
}

Kết quả:

Before: 1
After: 5

Function SwitchBuffer() không cần trả về một Pointer thông qua return. Thay vào đó, Function nhận địa chỉ của Pointer và cập nhật trực tiếp Pointer ở phía gọi.

9. Những lỗi thường gặp khi sử dụng Double Pointer

9.1. Không khởi tạo Double Pointer

Một Pointer chưa được khởi tạo có thể chứa giá trị không xác định. Nếu thực hiện Dereference Pointer này, chương trình có thể gặp hành vi không xác định. 

int **pptr;

/* Không an toàn */
**pptr = 100;

Trước khi sử dụng, cần đảm bảo Pointer trỏ đến một đối tượng hợp lệ và các cấp Pointer cần thiết đều đã được khởi tạo. 

int value = 10;

int *ptr = &value;
int **pptr = &ptr;

**pptr = 100;

9.2. Nhầm lẫn giữa *pptr và **pptr

Hai biểu thức này truy cập các cấp dữ liệu khác nhau. 

int value = 10;

int *ptr = &value;
int **pptr = &ptr;
  • *pptr truy cập Pointer ptr.
  • **pptr truy cập giá trị của biến value.

Nếu sử dụng nhầm cấp Dereference, chương trình có thể gặp lỗi kiểu dữ liệu hoặc thay đổi sai đối tượng.

9.3. Nhầm lẫn giữa địa chỉ Pointer và địa chỉ dữ liệu

Hãy xét: 

int value = 10;

int *ptr = &value;
int **pptr = &ptr;

Hai biểu thức ptr và pptr lưu những địa chỉ khác nhau:

  • ptr lưu địa chỉ của value.
  • pptr lưu địa chỉ của ptr.

Không nên nhầm lẫn địa chỉ của một biến thông thường với địa chỉ của Pointer đang tham chiếu đến biến đó.

9.4. Dereference khi Pointer là NULL

Pointer có thể được khởi tạo bằng NULL để thể hiện rằng nó hiện chưa trỏ đến một đối tượng hợp lệ. 

int *ptr = NULL;
int **pptr = &ptr;

/* Không hợp lệ vì ptr đang là NULL */
printf("%d\n", **pptr);

Trong ví dụ trên, pptr trỏ đến Pointer ptr một cách hợp lệ. Tuy nhiên, ptr đang là NULL. Vì vậy, Dereference đến cấp thứ hai là không hợp lệ.

Cần kiểm tra Pointer trước khi truy cập dữ liệu: 

if ((pptr != NULL) && (*pptr != NULL)) {
    printf("%d\n", **pptr);
}

9.5. Trả về địa chỉ của biến local

Khi sử dụng Double Pointer trong Function, cần chú ý Lifetime của các biến được trỏ đến. 

void GetValuePointer(int **pptr)
{
    int local_value = 100;

    *pptr = &local_value;
}

Đây là cách sử dụng không hợp lệ nếu Function gọi tiếp tục sử dụng Pointer sau khi GetValuePointer() kết thúc. Biến local_value có Automatic Storage Duration và không còn tồn tại sau khi Function kết thúc.

Cần sử dụng đối tượng có Lifetime phù hợp, chẳng hạn biến được khai báo ở phạm vi Function gọi hoặc vùng dữ liệu có Static Storage Duration.

9.6. Nhầm Double Pointer với Pointer to Array

Double Pointer và Pointer to Array có kiểu dữ liệu khác nhau. 

int **pptr;

int (*array_ptr)[3];
  • pptr trỏ đến một Pointer kiểu int *.
  • array_ptr trỏ đến một Array gồm 3 phần tử kiểu int.

Không thể thay thế hai kiểu Pointer này cho nhau chỉ vì cả hai đều có liên quan đến nhiều cấp truy cập dữ liệu.

Ghi nhớ: Khi sử dụng Multiple-level Pointer, cần kiểm tra từng cấp: Pointer hiện tại có được khởi tạo không, nó đang trỏ đến đối tượng nào và đối tượng đó còn tồn tại hay không.

10. Bảng tổng hợp các khái niệm

Khái niệm Ý nghĩa
Single Pointer Pointer lưu địa chỉ của một đối tượng dữ liệu.
Double Pointer Pointer lưu địa chỉ của một Pointer khác.
Multiple-level Pointer Pointer có nhiều cấp tham chiếu lồng nhau.
Dereference Truy cập đối tượng thông qua địa chỉ được lưu trong Pointer.
Output Parameter Tham số được sử dụng để Function cung cấp dữ liệu cho Function gọi.
Pointer-to-Pointer Một cách gọi khác để mô tả Pointer trỏ đến Pointer.
Array of Pointers Array mà mỗi phần tử là một Pointer.
Pointer to Array Pointer trỏ đến một Array hoàn chỉnh.
Pointer Lifetime Thời gian đối tượng được Pointer tham chiếu còn tồn tại.

Tóm tắt

Double Pointer là một Pointer lưu địa chỉ của một Pointer khác. Ví dụ int **pptr có nghĩa là pptr trỏ đến một Pointer kiểu int *.

Với một chuỗi Pointer gồm nhiều cấp, mỗi lần sử dụng toán tử Dereference * sẽ truy cập thêm một cấp. Vì vậy, *pptr truy cập Single Pointer, còn **pptr truy cập giá trị int cuối cùng.

Một ứng dụng quan trọng của Double Pointer là truyền địa chỉ Pointer vào Function. Điều này cho phép Function thay đổi địa chỉ mà Pointer ở Function gọi đang lưu hoặc cung cấp một Pointer thông qua Output Parameter.

Double Pointer cũng có thể được sử dụng cùng Array of Pointers để quản lý nhiều vùng dữ liệu độc lập. Tuy nhiên, Double Pointer không đồng nghĩa với Array of Pointers hoặc Pointer to Array.

Trong Embedded C, Double Pointer thường hữu ích khi quản lý Buffer, cung cấp địa chỉ dữ liệu thông qua API hoặc cập nhật trạng thái Pointer giữa các Module.

Khi sử dụng Multiple-level Pointer, cần đặc biệt chú ý đến việc khởi tạo Pointer, số cấp Dereference, NULL Pointer và Lifetime của đối tượng được tham chiếu.
