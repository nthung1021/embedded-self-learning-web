Bài 11: Pointer Arithmetic

Trong ngôn ngữ C, Pointer không chỉ được sử dụng để lưu trữ địa chỉ của một biến hoặc một vùng nhớ. Lập trình viên còn có thể thực hiện một số phép toán trên Pointer để di chuyển vị trí truy cập trong bộ nhớ.

Các phép toán này được gọi là Pointer Arithmetic. Chúng cho phép con trỏ tiến đến phần tử tiếp theo, lùi về phần tử trước đó hoặc xác định khoảng cách giữa hai con trỏ trong cùng một vùng dữ liệu phù hợp.

Pointer Arithmetic là một kỹ thuật quan trọng trong C, đặc biệt khi làm việc với Buffer, Array và các vùng nhớ liên tiếp. Trong Embedded C, kỹ thuật này thường được sử dụng khi xử lý dữ liệu nhận từ Communication Interface, đọc dữ liệu cảm biến hoặc duyệt qua một vùng Buffer.

Trong bài học này, chúng ta sẽ tập trung vào các phép toán cơ bản trên Pointer, cách con trỏ thay đổi địa chỉ dựa trên kiểu dữ liệu và những quy tắc cần tuân thủ khi thực hiện Pointer Arithmetic. Các nội dung chuyên sâu về Pointer to Array và Array of Pointers sẽ được trình bày trong Bài 12.

1. Tổng quan về Pointer Arithmetic

1.1. Pointer có thể thực hiện những phép toán nào?

Khác với một biến số nguyên thông thường, Pointer lưu trữ địa chỉ bộ nhớ. Vì vậy, các phép toán trên Pointer có những quy tắc riêng.

Trong C, những phép toán Pointer Arithmetic phổ biến bao gồm:

Phép toán Ý nghĩa Ví dụ
Increment Di chuyển Pointer đến phần tử tiếp theo. ptr++
Decrement Di chuyển Pointer về phần tử trước đó. ptr--
Addition Di chuyển Pointer tiến thêm một số phần tử. ptr + n
Subtraction Di chuyển Pointer lùi một số phần tử. ptr - n
Pointer Difference Tính khoảng cách giữa hai Pointer hợp lệ. ptr2 - ptr1

Điểm quan trọng nhất là Pointer Arithmetic không đơn giản là cộng hoặc trừ trực tiếp một số byte tùy ý. Compiler sẽ dựa vào kiểu dữ liệu mà Pointer đang trỏ đến để xác định mức thay đổi địa chỉ.

1.2. Pointer Arithmetic phụ thuộc vào Data Type

Khi thực hiện phép cộng hoặc trừ trên Pointer, địa chỉ được điều chỉnh theo kích thước của kiểu dữ liệu mà Pointer trỏ đến.

Ví dụ, nếu một Pointer có kiểu int * và sizeof(int) bằng 4 byte trên nền tảng đang sử dụng, khi thực hiện ptr++, địa chỉ Pointer sẽ tăng thêm 4 byte. 

#include <stdio.h>

int main(void)
{
    int value = 100;

    int *ptr = &value;

    printf("Address before: %p\n", (void *)ptr);

    ptr++;

    printf("Address after : %p\n", (void *)ptr);

    return 0;
}

Nếu sizeof(int) = 4, về mặt minh họa địa chỉ sau phép increment sẽ lớn hơn địa chỉ ban đầu 4 byte.

Lưu ý: Đoạn code trên chỉ minh họa cách tính địa chỉ của Pointer. Sau khi ptr++, Pointer không còn trỏ đến đối tượng value ban đầu. Không được dereference Pointer mới này vì nó không đại diện cho một đối tượng int hợp lệ trong ví dụ trên.

2. Pointer Increment và Decrement

2.1. Pointer Increment (ptr++)

Pointer Increment là phép toán tăng Pointer lên một vị trí phần tử tiếp theo.

Giả sử có một vùng dữ liệu gồm nhiều phần tử int liên tiếp. Khi Pointer đang trỏ đến một phần tử, việc thực hiện ptr++ sẽ khiến nó chuyển đến phần tử int tiếp theo. 

#include <stdio.h>

int main(void)
{
    int data[4] = {10, 20, 30, 40};

    int *ptr = &data[0];

    printf("Value: %d\n", *ptr);

    ptr++;

    printf("Value: %d\n", *ptr);

    ptr++;

    printf("Value: %d\n", *ptr);

    return 0;
}

Kết quả:

Value: 10
Value: 20
Value: 30

Trong ví dụ trên:

  • Ban đầu, ptr trỏ đến data[0].
  • Sau lần increment thứ nhất, ptr trỏ đến data[1].
  • Sau lần increment thứ hai, ptr trỏ đến data[2].

2.2. Pointer Decrement (ptr--)

Pointer Decrement hoạt động theo chiều ngược lại với Increment. Phép toán ptr-- đưa Pointer về phần tử liền trước. 

#include <stdio.h>

int main(void)
{
    int data[4] = {10, 20, 30, 40};

    int *ptr = &data[3];

    printf("Value: %d\n", *ptr);

    ptr--;

    printf("Value: %d\n", *ptr);

    ptr--;

    printf("Value: %d\n", *ptr);

    return 0;
}

Kết quả:

Value: 40
Value: 30
Value: 20

Ban đầu Pointer trỏ đến phần tử cuối cùng của Array. Sau mỗi lần decrement, Pointer di chuyển về phần tử đứng trước.

Ghi nhớ: Increment và Decrement chỉ hợp lệ khi Pointer được di chuyển trong phạm vi cho phép của cùng một Array hoặc đến vị trí one-past-the-end. Không được di chuyển Pointer tùy ý sang những vùng nhớ không liên quan.

3. Pointer Addition và Subtraction

3.1. Pointer + n

Ngoài việc tăng Pointer từng phần tử bằng ptr++, chúng ta có thể sử dụng phép cộng để di chuyển Pointer tiến thêm một số lượng phần tử xác định.

Cú pháp: 

ptr + n

Trong đó:

  • ptr là Pointer ban đầu.
  • n là số lượng phần tử cần di chuyển.

Ví dụ: 

#include <stdio.h>

int main(void)
{
    int data[5] = {10, 20, 30, 40, 50};

    int *ptr = data;

    printf("First element : %d\n", *ptr);
    printf("Third element : %d\n", *(ptr + 2));
    printf("Fifth element : %d\n", *(ptr + 4));

    return 0;
}

Kết quả:

First element : 10
Third element : 30
Fifth element : 50

Với ptr + 2, Pointer được di chuyển tiến thêm hai phần tử tính từ vị trí ban đầu. Toán tử * sau đó được sử dụng để truy cập giá trị tại vị trí mới.

3.2. Pointer - n

Phép trừ một số nguyên khỏi Pointer sẽ di chuyển Pointer lùi lại một số lượng phần tử tương ứng.

Ví dụ: 

#include <stdio.h>

int main(void)
{
    int data[5] = {10, 20, 30, 40, 50};

    int *ptr = &data[4];

    printf("Current value: %d\n", *ptr);

    printf("Previous value: %d\n", *(ptr - 1));

    printf("First value: %d\n", *(ptr - 4));

    return 0;
}

Kết quả:

Current value: 50
Previous value: 40
First value: 10

Trong ví dụ này, Pointer ban đầu trỏ đến phần tử thứ năm. Các phép trừ giúp truy cập những phần tử đứng trước mà không cần thay đổi giá trị của Pointer ban đầu.

3.3. So sánh ptr++, ptr + 1 và *(ptr + 1)

Ba biểu thức này có liên quan đến Pointer Arithmetic nhưng không có cùng ý nghĩa:

Biểu thức Ý nghĩa
ptr++ Tăng Pointer lên một phần tử và trả về giá trị Pointer trước khi tăng.
ptr + 1 Tạo giá trị Pointer mới ở vị trí tiếp theo, không thay đổi ptr.
*(ptr + 1) Truy cập giá trị tại phần tử tiếp theo mà không thay đổi ptr.

Ví dụ minh họa: 

#include <stdio.h>

int main(void)
{
    int data[3] = {10, 20, 30};

    int *ptr = data;

    printf("Current: %d\n", *ptr);

    printf("Next: %d\n", *(ptr + 1));

    printf("Current after access: %d\n", *ptr);

    ptr++;

    printf("Current after increment: %d\n", *ptr);

    return 0;
}

Kết quả:

Current: 10
Next: 20
Current after access: 10
Current after increment: 20

Có thể thấy *(ptr + 1) chỉ truy cập phần tử tiếp theo, trong khi ptr++ thực sự thay đổi vị trí mà Pointer đang lưu trữ.

4. Pointer Difference

4.1. Khái niệm Pointer Difference

Trong C, chúng ta có thể lấy hiệu của hai Pointer để xác định khoảng cách giữa chúng.

Cú pháp: 

ptr2 - ptr1

Kết quả không phải là số byte giữa hai địa chỉ. Thay vào đó, kết quả biểu diễn số lượng phần tử nằm giữa hai vị trí Pointer, theo kiểu dữ liệu mà chúng cùng trỏ đến. 

#include <stdio.h>
#include <stddef.h>

int main(void)
{
    int data[5] = {10, 20, 30, 40, 50};

    int *ptr1 = &data[1];
    int *ptr2 = &data[4];

    ptrdiff_t distance = ptr2 - ptr1;

    printf("Pointer distance: %td\n", distance);

    return 0;
}

Kết quả:

Pointer distance: 3

Giải thích:

  • ptr1 trỏ đến data[1].
  • ptr2 trỏ đến data[4].
  • Giữa hai vị trí có khoảng cách ba phần tử.

Kiểu dữ liệu ptrdiff_t được định nghĩa trong <stddef.h> và thường được sử dụng để lưu kết quả của phép trừ hai Pointer.

4.2. Điều kiện để thực hiện Pointer Difference

Không phải mọi cặp Pointer đều có thể thực hiện phép trừ. Theo quy tắc của C, hai Pointer phải trỏ đến các phần tử trong cùng một Array object hoặc vị trí one-past-the-end của Array đó.

Ví dụ hợp lệ: 

int data[5];

int *start = &data[0];
int *end   = &data[5];

ptrdiff_t count = end - start;

Trong ví dụ này, data[5] không phải là một phần tử thực tế của Array. Tuy nhiên, biểu thức &data[5] có thể được sử dụng để tạo Pointer one-past-the-end.

Pointer one-past-the-end là một vị trí đặc biệt nằm ngay sau phần tử cuối cùng của Array. Nó có thể được sử dụng để xác định điểm kết thúc khi duyệt dữ liệu, nhưng không được dereference.

Quan trọng: Không thực hiện phép trừ giữa hai Pointer trỏ đến hai đối tượng độc lập không thuộc cùng một Array. Hành vi này không được đảm bảo bởi chuẩn C và có thể dẫn đến Undefined Behavior.

5. Pointer Comparison

5.1. So sánh vị trí của hai Pointer

Trong C, chúng ta có thể sử dụng các toán tử so sánh như <, >, <= và >= để so sánh vị trí của Pointer trong cùng một Array object.

Ví dụ: 

#include <stdio.h>

int main(void)
{
    int data[5] = {10, 20, 30, 40, 50};

    int *ptr1 = &data[1];
    int *ptr2 = &data[3];

    if (ptr1 < ptr2) {
        printf("ptr1 is before ptr2\n");
    }

    if (ptr2 > ptr1) {
        printf("ptr2 is after ptr1\n");
    }

    return 0;
}

Kết quả:

ptr1 is before ptr2
ptr2 is after ptr1

Vì hai Pointer cùng trỏ đến các phần tử trong một Array, chúng ta có thể so sánh thứ tự vị trí của chúng.

5.2. Sử dụng Pointer Comparison để duyệt dữ liệu

Pointer Comparison có thể được kết hợp với Pointer Increment để duyệt qua một vùng dữ liệu. 

#include <stdio.h>

int main(void)
{
    int data[5] = {10, 20, 30, 40, 50};

    int *ptr = data;
    int *end = &data[5];

    while (ptr < end) {
        printf("%d\n", *ptr);
        ptr++;
    }

    return 0;
}

Kết quả:

10
20
30
40
50

Trong đoạn code trên:

  • ptr bắt đầu tại phần tử đầu tiên.
  • end lưu vị trí one-past-the-end.
  • Vòng lặp tiếp tục khi ptr vẫn nằm trước end.
  • Sau mỗi lần xử lý, Pointer được tăng lên một phần tử.
  • Khi Pointer đến vị trí end, vòng lặp kết thúc.
Cách duyệt này thường được sử dụng khi xử lý các vùng dữ liệu liên tiếp. Cần đảm bảo Pointer bắt đầu và Pointer kết thúc thuộc cùng một Array object hoặc cùng một vùng dữ liệu hợp lệ theo quy tắc của C.

6. Pointer Arithmetic và Memory Address

6.1. Địa chỉ thay đổi theo kích thước kiểu dữ liệu

Một trong những đặc điểm quan trọng nhất của Pointer Arithmetic là địa chỉ được điều chỉnh theo kích thước kiểu dữ liệu mà Pointer trỏ đến.

Ví dụ, xét các Pointer có kiểu dữ liệu khác nhau: 

char  *char_ptr;
short *short_ptr;
int   *int_ptr;
float *float_ptr;

Nếu thực hiện phép toán ptr + 1, mức thay đổi địa chỉ sẽ tương ứng với sizeof(*ptr).

Pointer Type Kích thước minh họa Địa chỉ thay đổi khi +1
char * 1 byte 1 byte
short * 2 byte 2 byte
int * 4 byte 4 byte
float * 4 byte 4 byte

Các kích thước trên chỉ mang tính minh họa. Kích thước thực tế phụ thuộc vào implementation và kiến trúc nền tảng.

6.2. Ví dụ kiểm tra kích thước bước di chuyển

#include <stdio.h>

int main(void)
{
    int data[3] = {10, 20, 30};

    int *ptr = data;

    printf("Size of int: %zu bytes\n", sizeof(int));

    printf("Address 1: %p\n", (void *)ptr);

    ptr++;

    printf("Address 2: %p\n", (void *)ptr);

    return 0;
}

Nếu sizeof(int) bằng 4 byte, địa chỉ của Pointer sau phép increment sẽ tăng tương ứng 4 byte.

Điều này cho thấy Pointer Arithmetic hoạt động dựa trên kiểu dữ liệu, chứ không phải chỉ đơn thuần tăng hoặc giảm địa chỉ theo một byte.

7. Pointer Arithmetic trong Embedded C

7.1. Duyệt qua một Data Buffer

Trong Embedded Systems, dữ liệu thường được lưu trữ trong các Buffer có kích thước cố định. Ví dụ, một ECU có thể nhận dữ liệu từ CAN, UART hoặc SPI và lưu vào một vùng nhớ để xử lý.

Pointer Arithmetic có thể được sử dụng để duyệt qua các phần tử trong Buffer này. 

#include <stdint.h>
#include <stdio.h>

#define BUFFER_SIZE    6U

int main(void)
{
    uint8_t rx_buffer[BUFFER_SIZE] = {
        0x10U, 0x20U, 0x30U,
        0x40U, 0x50U, 0x60U
    };

    uint8_t *ptr = rx_buffer;
    uint8_t *end = &rx_buffer[BUFFER_SIZE];

    while (ptr < end) {
        printf("Data: 0x%02X\n", (unsigned int)*ptr);

        ptr++;
    }

    return 0;
}

Kết quả: 

Data: 0x10
Data: 0x20
Data: 0x30
Data: 0x40
Data: 0x50
Data: 0x60

Vì uint8_t có kích thước 1 byte, mỗi lần increment sẽ đưa Pointer đến byte tiếp theo trong Buffer.

7.2. Tính toán số lượng phần tử đã xử lý

Trong một số trường hợp, chúng ta cần xác định đã xử lý bao nhiêu phần tử trong Buffer. Pointer Difference có thể được sử dụng cho mục đích này. 

#include <stdint.h>
#include <stddef.h>
#include <stdio.h>

#define BUFFER_SIZE    8U

int main(void)
{
    uint8_t buffer[BUFFER_SIZE] = {0U};

    uint8_t *start = buffer;
    uint8_t *current = buffer;

    current += 5;

    ptrdiff_t processed = current - start;

    printf("Processed elements: %td\n", processed);

    return 0;
}

Kết quả:

Processed elements: 5

Trong ví dụ này, Pointer current đã di chuyển năm phần tử tính từ vị trí ban đầu. Phép trừ hai Pointer giúp xác định số lượng phần tử đã đi qua.

Ứng dụng Embedded: Pointer Arithmetic có thể hỗ trợ xử lý các vùng Buffer trong Communication Driver, Data Acquisition và các module xử lý dữ liệu. Tuy nhiên, khi làm việc với Buffer thực tế, lập trình viên vẫn phải kiểm tra kích thước và giới hạn vùng nhớ trước khi truy cập.

8. Những lỗi thường gặp khi sử dụng Pointer Arithmetic

8.1. Truy cập vượt quá giới hạn Array

Một lỗi phổ biến là tiếp tục tăng Pointer vượt quá vị trí one-past-the-end hoặc dereference Pointer tại vị trí one-past-the-end. 

int data[3] = {10, 20, 30};

int *ptr = data;

ptr += 3;

/* Không hợp lệ: ptr đang ở vị trí one-past-the-end */
printf("%d\n", *ptr);

Pointer có thể được đưa đến vị trí ngay sau phần tử cuối cùng, nhưng không được sử dụng để đọc hoặc ghi dữ liệu tại vị trí đó.

8.2. Di chuyển Pointer ra ngoài vùng dữ liệu hợp lệ

int data[3] = {10, 20, 30};

int *ptr = data;

ptr += 5;  /* Không hợp lệ */

Trong ví dụ trên, phép toán tạo ra Pointer nằm ngoài phạm vi cho phép của Array. Đây là hành vi không được đảm bảo bởi chuẩn C.

8.3. Nhầm lẫn giữa số byte và số phần tử

Một số lập trình viên mới học Pointer thường nghĩ rằng ptr + 2 luôn có nghĩa là địa chỉ tăng thêm 2 byte. Tuy nhiên, điều này không chính xác. 

int data[5];

int *ptr = data;

ptr + 2;

Nếu sizeof(int) bằng 4 byte, biểu thức trên tương ứng với vị trí cách Pointer ban đầu 8 byte.

Vì vậy, cần phân biệt rõ:

  • Pointer Arithmetic: di chuyển theo số lượng phần tử.
  • Byte Offset: khoảng cách được tính theo byte.

8.4. Thực hiện Pointer Arithmetic trên Pointer không phù hợp

Pointer Arithmetic cần được sử dụng với kiểu Pointer phù hợp và trong phạm vi đối tượng mà Pointer được phép tham chiếu.

Ví dụ, phép cộng hoặc trừ trực tiếp trên một Pointer kiểu void * không được định nghĩa trong chuẩn C. Khác với một số compiler extension, C chuẩn không quy định kích thước phần tử của void để thực hiện phép toán này. 

void *ptr;

/* Không hợp lệ trong C chuẩn */
ptr++;

Nếu cần duyệt dữ liệu dạng byte, có thể sử dụng Pointer kiểu uint8_t * hoặc unsigned char * tùy theo mục đích sử dụng.

Ghi nhớ: Không phải mọi phép toán có thể được compiler chấp nhận đều đảm bảo hành vi hợp lệ theo chuẩn C. Đặc biệt trong Embedded C, việc truy cập sai vùng nhớ có thể gây ra lỗi khó phát hiện hoặc làm hệ thống hoạt động không ổn định.

9. Tổng hợp các phép toán Pointer Arithmetic

Biểu thức Chức năng Thay đổi Pointer gốc?
ptr++ Tăng Pointer một phần tử. Có
ptr-- Giảm Pointer một phần tử. Có
ptr + n Tạo Pointer tiến thêm n phần tử. Không
ptr - n Tạo Pointer lùi n phần tử. Không

Tóm tắt

Pointer Arithmetic cho phép lập trình viên C di chuyển Pointer giữa các phần tử của một vùng dữ liệu liên tiếp. Các phép toán như Increment, Decrement, Addition và Subtraction đều được tính dựa trên kích thước kiểu dữ liệu mà Pointer trỏ đến.

Bên cạnh đó, Pointer Difference và Pointer Comparison có thể được sử dụng để xác định khoảng cách hoặc kiểm tra vị trí của các Pointer trong cùng một Array object.

Đối với Embedded C, Pointer Arithmetic là kỹ thuật hữu ích khi xử lý Buffer và các vùng dữ liệu liên tiếp. Tuy nhiên, lập trình viên phải luôn kiểm soát phạm vi Pointer, tránh truy cập vượt giới hạn và tuân thủ các quy tắc của chuẩn C để đảm bảo chương trình hoạt động an toàn.
