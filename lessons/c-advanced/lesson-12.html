Bài 12: Pointer to Array vs Array of Pointers

Trong ngôn ngữ C, Array và Pointer có mối quan hệ rất chặt chẽ. Chúng thường được sử dụng cùng nhau khi xử lý dữ liệu, truy cập bộ nhớ hoặc truyền Buffer giữa các Function.

Tuy nhiên, có hai cách khai báo rất dễ gây nhầm lẫn đối với người mới học: Pointer to Array và Array of Pointers. Mặc dù cả hai đều chứa thành phần Pointer và Array, bản chất kiểu dữ liệu cũng như cách chúng được sử dụng hoàn toàn khác nhau.

Việc hiểu rõ sự khác biệt này rất quan trọng trong Advanced C Embedded, đặc biệt khi làm việc với các vùng dữ liệu nhiều chiều, danh sách Buffer, bảng cấu hình hoặc các cấu trúc dữ liệu được tổ chức bằng Pointer.

Trong bài học này, chúng ta sẽ tập trung vào cách khai báo, đọc cú pháp, tổ chức bộ nhớ và truy cập dữ liệu của Pointer to Array và Array of Pointers. Nội dung về Double Pointer và Multiple-level Pointer sẽ được trình bày riêng trong Bài 13.

1. Tổng quan về Pointer to Array và Array of Pointers

1.1. Pointer to Array là gì?

Pointer to Array là một Pointer có khả năng lưu địa chỉ của một Array hoàn chỉnh.

Khác với một Pointer thông thường trỏ đến một phần tử đơn lẻ, Pointer to Array đại diện cho địa chỉ của toàn bộ một Array có kích thước và kiểu phần tử xác định.

Cú pháp khai báo:

data_type (*ptr)[array_size];

Trong đó:

  • data_type: Kiểu dữ liệu của từng phần tử trong Array.
  • ptr: Tên Pointer.
  • array_size: Số lượng phần tử của Array mà Pointer trỏ đến.
  • (*ptr): Dấu ngoặc đơn xác định rằng ptr là Pointer trước khi áp dụng khai báo Array.

Ví dụ:

int (*ptr)[5];

Khai báo trên có nghĩa là ptr là một Pointer trỏ đến một Array gồm 5 phần tử kiểu int.

1.2. Array of Pointers là gì?

Array of Pointers là một Array mà mỗi phần tử của Array đó là một Pointer.

Thay vì lưu trực tiếp các giá trị như một Array thông thường, Array of Pointers lưu nhiều địa chỉ bộ nhớ khác nhau.

Cú pháp khai báo:

data_type *ptr[array_size];

Trong đó:

  • data_type: Kiểu dữ liệu mà các Pointer sẽ trỏ đến.
  • ptr: Tên Array.
  • array_size: Số lượng Pointer trong Array.
  • *ptr[array_size]: Một Array gồm nhiều phần tử kiểu Pointer.

Ví dụ:

int *ptr[5];

Khai báo trên có nghĩa là ptr là một Array gồm 5 phần tử, trong đó mỗi phần tử là một Pointer kiểu int *.

1.3. So sánh nhanh hai cách khai báo

Đặc điểm Pointer to Array Array of Pointers
Khai báo int (*ptr)[5]; int *ptr[5];
Bản chất Một Pointer. Một Array.
Đối tượng lưu trữ Địa chỉ của một Array. Nhiều địa chỉ Pointer.
Số lượng phần tử Pointer Một Pointer. Nhiều Pointer.
Kiểu dữ liệu Pointer đến Array gồm 5 phần tử int. Array gồm 5 Pointer đến int.
Điểm cần nhớ: int (*ptr)[5] và int *ptr[5] không giống nhau. Dấu ngoặc đơn trong khai báo đầu tiên làm thay đổi cách Compiler phân tích toàn bộ biểu thức khai báo.

2. Cách đọc và phân tích Pointer Declaration

2.1. Vai trò của dấu ngoặc đơn

Trong C, các toán tử khai báo như * và [] có mức độ ưu tiên khác nhau. Toán tử Array Subscript [] có độ ưu tiên cao hơn toán tử Dereference *.

Vì vậy, hai khai báo dưới đây được Compiler hiểu theo hai cách khác nhau: 

int *ptr[5];

int (*ptr)[5];

Đối với khai báo thứ nhất: 

int *ptr[5];

Compiler xử lý ptr[5] trước, xác định đây là một Array có 5 phần tử. Sau đó, dấu * cho biết mỗi phần tử của Array là một Pointer đến int.

Đối với khai báo thứ hai: 

int (*ptr)[5];

Dấu ngoặc đơn khiến Compiler xác định *ptr trước. Điều này có nghĩa ptr là một Pointer. Phần [5] tiếp theo xác định đối tượng mà Pointer trỏ đến là một Array gồm 5 phần tử kiểu int.

2.2. Quy tắc đọc khai báo C

Khi gặp một khai báo Pointer phức tạp, có thể sử dụng cách phân tích từ tên biến ra ngoài:

  • Bắt đầu từ tên biến được khai báo.
  • Kiểm tra dấu ngoặc đơn bao quanh tên biến và toán tử Pointer.
  • Phân tích các toán tử [] hoặc () theo thứ tự ưu tiên.
  • Cuối cùng xác định kiểu dữ liệu cơ sở.

Ví dụ:

Khai báo Cách đọc
int *ptr[5] Array 5 phần tử, mỗi phần tử là Pointer đến int.
int (*ptr)[5] Pointer đến Array gồm 5 phần tử int.
char *names[3] Array 3 Pointer đến char.
char (*name)[20] Pointer đến Array gồm 20 phần tử char.

3. Pointer to Array

3.1. Khai báo và khởi tạo Pointer to Array

Để hiểu rõ cách hoạt động của Pointer to Array, chúng ta bắt đầu với một Array thông thường gồm 5 phần tử kiểu int. 

#include <stdio.h>

int main(void)
{
    int data[5] = {10, 20, 30, 40, 50};

    int (*ptr)[5] = &data;

    printf("First element: %d\n", (*ptr)[0]);
    printf("Second element: %d\n", (*ptr)[1]);
    printf("Third element: %d\n", (*ptr)[2]);

    return 0;
}

Kết quả:

First element: 10
Second element: 20
Third element: 30

Giải thích:

  • data là một Array gồm 5 phần tử kiểu int.
  • &data là địa chỉ của toàn bộ Array.
  • ptr được khai báo để trỏ đến một Array có 5 phần tử kiểu int.
  • *ptr biểu diễn Array mà Pointer đang trỏ đến.
  • (*ptr)[0] truy cập phần tử đầu tiên của Array.

3.2. Phân biệt data, &data và &data[0]

Đây là ba biểu thức thường xuất hiện khi làm việc với Array và Pointer. Mặc dù chúng có thể biểu diễn địa chỉ bắt đầu của cùng một vùng dữ liệu, kiểu dữ liệu của chúng không giống nhau. 

int data[5] = {10, 20, 30, 40, 50};

data;
&data[0];
&data;
Biểu thức Kiểu dữ liệu Ý nghĩa
data int * trong hầu hết biểu thức Array được chuyển đổi thành Pointer đến phần tử đầu tiên.
&data[0] int * Địa chỉ của phần tử đầu tiên.
&data int (*)[5] Địa chỉ của toàn bộ Array.

Mặc dù các biểu thức trên thường có cùng địa chỉ bắt đầu về mặt biểu diễn địa chỉ, chúng có kiểu Pointer khác nhau. Điều này ảnh hưởng trực tiếp đến Pointer Arithmetic.

3.3. Pointer Arithmetic với Pointer to Array

Khi thực hiện Pointer Arithmetic trên Pointer to Array, Pointer sẽ di chuyển theo kích thước của toàn bộ Array mà nó trỏ đến. 

#include <stdio.h>

int main(void)
{
    int data[2][3] = {
        {10, 20, 30},
        {40, 50, 60}
    };

    int (*ptr)[3] = data;

    printf("First row, first element: %d\n", (*ptr)[0]);
    printf("First row, second element: %d\n", (*ptr)[1]);

    ptr++;

    printf("Second row, first element: %d\n", (*ptr)[0]);
    printf("Second row, second element: %d\n", (*ptr)[1]);

    return 0;
}

Kết quả:

First row, first element: 10
First row, second element: 20
Second row, first element: 40
Second row, second element: 50

Giải thích:

  • data là một Array hai chiều có 2 hàng và 3 cột.
  • int (*ptr)[3] là Pointer trỏ đến một Array gồm 3 phần tử kiểu int.
  • Ban đầu, ptr trỏ đến hàng đầu tiên.
  • Sau ptr++, Pointer chuyển đến hàng tiếp theo.

Nếu sizeof(int) = 4, mỗi hàng có kích thước 3 × 4 = 12 byte. Do đó, ptr++ sẽ di chuyển Pointer một khoảng tương ứng với kích thước của một hàng.

Ghi nhớ: Pointer to Array rất hữu ích khi cần duyệt hoặc truyền các vùng dữ liệu có cấu trúc theo hàng và cột. Kiểu dữ liệu của Pointer cho phép Compiler xác định kích thước mỗi bước di chuyển.

4. Array of Pointers

4.1. Khai báo và khởi tạo Array of Pointers

Array of Pointers là một Array mà mỗi phần tử lưu một địa chỉ. Chúng ta có thể khai báo một Array gồm 3 Pointer kiểu int * như sau: 

int *ptr[3];

Để hiểu rõ cách sử dụng, hãy xét ví dụ sau: 

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 20;
    int c = 30;

    int *ptr[3];

    ptr[0] = &a;
    ptr[1] = &b;
    ptr[2] = &c;

    printf("Value 1: %d\n", *ptr[0]);
    printf("Value 2: %d\n", *ptr[1]);
    printf("Value 3: %d\n", *ptr[2]);

    return 0;
}

Kết quả:

Value 1: 10
Value 2: 20
Value 3: 30

Giải thích:

  • a, b và c là ba biến int độc lập.
  • ptr là Array gồm 3 Pointer.
  • ptr[0] lưu địa chỉ của a.
  • ptr[1] lưu địa chỉ của b.
  • ptr[2] lưu địa chỉ của c.
  • Toán tử * được sử dụng để truy cập giá trị thông qua từng Pointer.

4.2. Khởi tạo Array of Pointers trực tiếp

Thay vì khai báo Array rồi gán từng Pointer riêng biệt, chúng ta có thể khởi tạo các phần tử ngay khi khai báo. 

#include <stdio.h>

int main(void)
{
    int value1 = 100;
    int value2 = 200;
    int value3 = 300;

    int *ptr[3] = {
        &value1,
        &value2,
        &value3
    };

    for (int i = 0; i < 3; i++) {
        printf("Value %d: %d\n", i, *ptr[i]);
    }

    return 0;
}

Kết quả:

Value 0: 100
Value 1: 200
Value 2: 300

Cách khởi tạo này giúp mã nguồn ngắn gọn hơn và thể hiện rõ mỗi phần tử trong Array đang trỏ đến đối tượng nào.

4.3. Array of Pointers trỏ đến các Array khác nhau

Một ứng dụng phổ biến của Array of Pointers là lưu địa chỉ của nhiều Array hoặc vùng dữ liệu riêng biệt. 

#include <stdio.h>

int main(void)
{
    int group1[] = {10, 20, 30};
    int group2[] = {40, 50, 60};
    int group3[] = {70, 80, 90};

    int *groups[3] = {
        group1,
        group2,
        group3
    };

    printf("Group 1: %d %d %d\n",
           groups[0][0], groups[0][1], groups[0][2]);

    printf("Group 2: %d %d %d\n",
           groups[1][0], groups[1][1], groups[1][2]);

    printf("Group 3: %d %d %d\n",
           groups[2][0], groups[2][1], groups[2][2]);

    return 0;
}

Kết quả:

Group 1: 10 20 30
Group 2: 40 50 60
Group 3: 70 80 90

Trong ví dụ này:

  • group1, group2 và group3 là ba Array độc lập.
  • groups là Array gồm 3 Pointer kiểu int *.
  • Mỗi Pointer lưu địa chỉ phần tử đầu tiên của một Array tương ứng.
  • groups[1][2] truy cập phần tử thứ ba của group2.
Lưu ý: Các Array được sử dụng trong ví dụ có cùng kiểu phần tử. Array of Pointers không yêu cầu các vùng dữ liệu được trỏ đến phải nằm liên tiếp trong bộ nhớ.

5. So sánh cách tổ chức bộ nhớ

5.1. Memory Layout của Pointer to Array

Xét ví dụ: 

int data[4] = {10, 20, 30, 40};

int (*ptr)[4] = &data;

Có thể hình dung cách tổ chức dữ liệu như sau: 

Pointer ptr
    |
    | stores address of entire array
    v
+--------+--------+--------+--------+
| data[0]| data[1]| data[2]| data[3]|
+--------+--------+--------+--------+
|   10   |   20   |   30   |   40   |
+--------+--------+--------+--------+

Pointer ptr lưu địa chỉ của toàn bộ Array. Các phần tử của Array nằm liên tiếp trong bộ nhớ theo quy tắc tổ chức Array của C.

5.2. Memory Layout của Array of Pointers

Xét ví dụ: 

int a = 10;
int b = 20;
int c = 30;

int *ptr[3] = {&a, &b, &c};

Có thể hình dung cách tổ chức dữ liệu như sau: 

Array of Pointers
+----------+----------+----------+
| ptr[0]   | ptr[1]   | ptr[2]   |
+----------+----------+----------+
     |          |          |
     v          v          v
   +----+     +----+     +----+
   | 10 |     | 20 |     | 30 |
   +----+     +----+     +----+
      a          b          c

Trong trường hợp này, Array ptr lưu ba địa chỉ khác nhau. Các biến a, b và c là những đối tượng độc lập; chúng không cần nằm liên tiếp trong bộ nhớ.

5.3. Khác biệt về kích thước bộ nhớ

Kích thước bộ nhớ của hai khai báo cũng khác nhau. Hãy xét: 

int (*ptr1)[5];

int *ptr2[5];

Với ptr1, đây là một Pointer đến Array. Kích thước của nó bằng kích thước của một Pointer trên nền tảng đang sử dụng.

Với ptr2, đây là một Array gồm 5 Pointer. Kích thước toàn bộ Array bằng 5 lần kích thước của một Pointer, không tính padding bổ sung nếu implementation có yêu cầu đặc biệt. 

#include <stdio.h>

int main(void)
{
    int (*ptr1)[5];
    int *ptr2[5];

    printf("Size of ptr1: %zu bytes\n", sizeof(ptr1));
    printf("Size of ptr2: %zu bytes\n", sizeof(ptr2));

    printf("Size of one pointer: %zu bytes\n", sizeof(ptr2[0]));

    return 0;
}

Ví dụ, trên một nền tảng mà kích thước Pointer là 4 byte, kết quả có thể là: 

Size of ptr1: 4 bytes
Size of ptr2: 20 bytes
Size of one pointer: 4 bytes

Trên nền tảng khác, đặc biệt là hệ thống 64-bit, kích thước Pointer có thể là 8 byte. Vì vậy, không nên mặc định kích thước Pointer luôn là 4 byte.

Quan trọng: sizeof(ptr1) trả về kích thước của Pointer, không phải kích thước Array mà Pointer trỏ đến. Trong khi đó, sizeof(ptr2) trả về kích thước của toàn bộ Array gồm 5 Pointer.

6. Pointer to Array và Array of Pointers với dữ liệu nhiều chiều

6.1. Array hai chiều thông thường

Trong C, một Array hai chiều có thể được khai báo như sau: 

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

Đây là một Array gồm 2 phần tử, trong đó mỗi phần tử lại là một Array gồm 3 số nguyên.

Có thể khai báo Pointer to Array để trỏ đến từng hàng: 

int (*row_ptr)[3] = matrix;

Khi thực hiện row_ptr++, Pointer sẽ chuyển đến hàng tiếp theo của Matrix.

6.2. Truy cập dữ liệu bằng Pointer to Array

#include <stdio.h>

int main(void)
{
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    int (*ptr)[3] = matrix;

    for (int row = 0; row < 2; row++) {
        for (int col = 0; col < 3; col++) {
            printf("%d ", ptr[row][col]);
        }

        printf("\n");
    }

    return 0;
}

Kết quả:

1 2 3
4 5 6

Trong ví dụ này, Pointer được khai báo với kiểu int (*)[3], nghĩa là nó trỏ đến một hàng gồm 3 phần tử kiểu int.

6.3. Array of Pointers với các vùng dữ liệu khác nhau

Không giống Array hai chiều thông thường, Array of Pointers có thể lưu địa chỉ của nhiều vùng dữ liệu độc lập. 

#include <stdio.h>

int main(void)
{
    int row1[] = {1, 2, 3};
    int row2[] = {4, 5};
    int row3[] = {6, 7, 8, 9};

    int *rows[3] = {
        row1,
        row2,
        row3
    };

    int sizes[3] = {3, 2, 4};

    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < sizes[i]; j++) {
            printf("%d ", rows[i][j]);
        }

        printf("\n");
    }

    return 0;
}

Kết quả:

1 2 3
4 5
6 7 8 9

Điểm khác biệt đáng chú ý là mỗi Pointer trong Array có thể trỏ đến một vùng dữ liệu có số lượng phần tử khác nhau. Vì vậy, chúng ta cần lưu thêm thông tin kích thước của từng vùng nếu muốn duyệt dữ liệu một cách an toàn.

Phân biệt: Array hai chiều thông thường có các hàng nằm liên tiếp trong cùng một Array object. Array of Pointers chỉ lưu các địa chỉ và không đảm bảo các vùng dữ liệu được trỏ đến nằm liên tiếp trong bộ nhớ.

7. Ứng dụng trong Embedded C

7.1. Pointer to Array trong xử lý dữ liệu theo hàng

Trong Embedded Systems, dữ liệu đôi khi được tổ chức theo nhiều nhóm có cấu trúc giống nhau. Ví dụ, một hệ thống có thể lưu các bộ thông số của nhiều cảm biến trong một Matrix.

Pointer to Array có thể được sử dụng để truy cập từng nhóm dữ liệu theo hàng. 

#include <stdint.h>
#include <stdio.h>

#define SENSOR_COUNT       2U
#define PARAMETER_COUNT    3U

int main(void)
{
    uint16_t sensor_data[SENSOR_COUNT][PARAMETER_COUNT] = {
        {250U, 300U, 350U},
        {400U, 450U, 500U}
    };

    uint16_t (*sensor_ptr)[PARAMETER_COUNT] = sensor_data;

    for (uint32_t i = 0U; i < SENSOR_COUNT; i++) {
        printf("Sensor %lu: ", (unsigned long)i);

        for (uint32_t j = 0U; j < PARAMETER_COUNT; j++) {
            printf("%u ", (unsigned int)sensor_ptr[i][j]);
        }

        printf("\n");
    }

    return 0;
}

Trong ví dụ này, mỗi hàng đại diện cho một nhóm thông số của Sensor. Pointer to Array cho phép truy cập các hàng với cấu trúc dữ liệu có kích thước cố định.

7.2. Array of Pointers trong quản lý các Buffer

Một hệ thống Embedded có thể có nhiều Buffer riêng biệt phục vụ cho các mục đích khác nhau, chẳng hạn:

  • UART Receive Buffer.
  • UART Transmit Buffer.
  • CAN Receive Buffer.

Array of Pointers có thể được sử dụng để lưu địa chỉ bắt đầu của các Buffer này. 

#include <stdint.h>
#include <stdio.h>

#define BUFFER_COUNT    3U

int main(void)
{
    uint8_t uart_rx_buffer[4] = {
        0x10U, 0x20U, 0x30U, 0x40U
    };

    uint8_t uart_tx_buffer[3] = {
        0xA1U, 0xA2U, 0xA3U
    };

    uint8_t can_rx_buffer[5] = {
        0x11U, 0x22U, 0x33U, 0x44U, 0x55U
    };

    uint8_t *buffers[BUFFER_COUNT] = {
        uart_rx_buffer,
        uart_tx_buffer,
        can_rx_buffer
    };

    uint8_t buffer_sizes[BUFFER_COUNT] = {
        4U, 3U, 5U
    };

    for (uint32_t i = 0U; i < BUFFER_COUNT; i++) {
        printf("Buffer %lu: ",
               (unsigned long)i);

        for (uint32_t j = 0U; j < buffer_sizes[i]; j++) {
            printf("%02X ",
                   (unsigned int)buffers[i][j]);
        }

        printf("\n");
    }

    return 0;
}

Kết quả:

Buffer 0: 10 20 30 40
Buffer 1: A1 A2 A3
Buffer 2: 11 22 33 44 55

Trong ví dụ trên, Array buffers lưu địa chỉ của ba Buffer khác nhau. Mỗi Buffer có kích thước riêng và được quản lý thông qua mảng buffer_sizes.

Cách tổ chức này giúp chương trình có thể xử lý nhiều vùng dữ liệu thông qua một cấu trúc Pointer chung.

Ứng dụng thực tế: Array of Pointers có thể hữu ích khi quản lý nhiều Buffer hoặc nhiều nhóm dữ liệu có cùng kiểu phần tử nhưng kích thước khác nhau. Trong firmware thực tế, cần đảm bảo các Pointer được khởi tạo hợp lệ và kích thước Buffer luôn được kiểm soát.

8. Những lỗi thường gặp

8.1. Nhầm lẫn giữa Pointer to Array và Array of Pointers

Đây là lỗi phổ biến nhất khi khai báo Pointer phức tạp. 

int (*ptr1)[5];

int *ptr2[5];

Hai khai báo trên có bản chất khác nhau:

  • ptr1 là một Pointer.
  • ptr2 là một Array gồm 5 Pointer.

Việc nhầm lẫn có thể dẫn đến lỗi khi khởi tạo, truyền tham số hoặc truy cập dữ liệu.

8.2. Không khởi tạo Pointer trong Array of Pointers

Khi khai báo một Array of Pointers mà không khởi tạo các phần tử, các Pointer có thể chứa giá trị không xác định nếu chúng là biến automatic không được khởi tạo. 

int *ptr[3];

/* Không nên dereference khi chưa khởi tạo */
printf("%d\n", *ptr[0]);

Cần gán địa chỉ hợp lệ cho từng Pointer trước khi sử dụng. Nếu chưa có đối tượng phù hợp, có thể khởi tạo các phần tử bằng NULL và kiểm tra trước khi dereference. 

int *ptr[3] = {
    NULL,
    NULL,
    NULL
};

8.3. Trỏ đến Array có kích thước không phù hợp

Pointer to Array có kiểu dữ liệu bao gồm số lượng phần tử trong Array mà nó trỏ đến. 

int data[5];

int (*ptr)[5] = &data;

Trong ví dụ này, ptr có kiểu int (*)[5]. Không thể tùy ý thay thế bằng Pointer đến Array có số lượng phần tử khác mà không xem xét sự tương thích kiểu dữ liệu.

8.4. Sử dụng Pointer sau khi đối tượng hết Lifetime

Một Array of Pointers có thể lưu địa chỉ của các biến hoặc Array khác. Tuy nhiên, các đối tượng được trỏ đến phải còn tồn tại trong thời gian Pointer được sử dụng.

Ví dụ, nếu một Function trả về địa chỉ của một biến local có Automatic Storage Duration, Pointer nhận được sẽ không còn trỏ đến một đối tượng hợp lệ sau khi Function kết thúc.

Vì vậy, cần chú ý Lifetime của đối tượng khi lưu địa chỉ vào Array of Pointers.

8.5. Truy cập vượt quá giới hạn Array

Cả Pointer to Array và Array of Pointers đều cần được sử dụng đúng giới hạn. 

int value1 = 10;
int value2 = 20;

int *ptr[2] = {
    &value1,
    &value2
};

/* Không hợp lệ: Array chỉ có hai phần tử */
printf("%d\n", *ptr[2]);

Các phần tử hợp lệ của Array trên là ptr[0] và ptr[1]. Truy cập ptr[2] sẽ vượt quá giới hạn Array.

Ghi nhớ: Khi sử dụng Array of Pointers, cần kiểm tra cả hai cấp: chỉ số của Array Pointer và tính hợp lệ của vùng nhớ mà mỗi Pointer đang trỏ đến.

Tóm tắt

Pointer to Array và Array of Pointers là hai khái niệm khác nhau trong ngôn ngữ C, mặc dù cú pháp khai báo của chúng khá giống nhau.

Pointer to Array là một Pointer trỏ đến một Array hoàn chỉnh. Ví dụ int (*ptr)[5] có nghĩa là Pointer trỏ đến một Array gồm 5 phần tử kiểu int.

Array of Pointers là một Array chứa nhiều Pointer. Ví dụ int *ptr[5] có nghĩa là một Array gồm 5 phần tử, mỗi phần tử là Pointer đến int.

Sự khác biệt này ảnh hưởng đến cách tổ chức bộ nhớ, kích thước biến, Pointer Arithmetic và cách truy cập dữ liệu. Pointer to Array thường phù hợp khi làm việc với các Array có cấu trúc cố định hoặc dữ liệu nhiều chiều. Trong khi đó, Array of Pointers hữu ích khi cần quản lý nhiều vùng dữ liệu hoặc nhiều Buffer độc lập.

Hiểu rõ hai cách khai báo này là nền tảng quan trọng để tiếp tục nghiên cứu các kỹ thuật Pointer nâng cao trong C và Embedded Systems.
