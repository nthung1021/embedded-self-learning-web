Bài 14: Function Pointer & Callback Function

Trong C, Pointer không chỉ được sử dụng để lưu địa chỉ của Variable hoặc Array mà còn có thể lưu địa chỉ của một Function. Cơ chế này được gọi là Function Pointer.

Thông qua Function Pointer, chương trình có thể lựa chọn và gọi Function trong quá trình Runtime thay vì phải cố định Function được gọi ngay tại thời điểm viết mã nguồn.

Một ứng dụng quan trọng của Function Pointer là Callback Function. Đây là kỹ thuật truyền một Function vào một Function khác để Function nhận có thể gọi lại Function được truyền vào khi cần thiết.

Trong Embedded Systems, Function Pointer và Callback thường được sử dụng trong Driver Interface, Event Handler, Timer Callback, Communication Module và các cơ chế xử lý sự kiện.

Trong bài học này, chúng ta sẽ tập trung vào cách khai báo Function Pointer, cách gọi Function thông qua Pointer và cách xây dựng Callback Function. Các kỹ thuật thiết kế Event-driven Programming ở mức hệ thống sẽ được trình bày sâu hơn trong những bài học sau.

1. Tổng quan về Function Pointer

1.1. Function trong C và địa chỉ của Function

Trong C, mỗi Function được biên dịch thành một đoạn mã máy nằm trong vùng nhớ chương trình. Function có thể được gọi thông qua tên của nó.

Ví dụ:

#include <stdio.h>

void say_hello(void)
{
    printf("Hello Embedded C!\n");
}

int main(void)
{
    say_hello();

    return 0;
}

Trong ví dụ trên, say_hello() là một Function không nhận tham số và không trả về giá trị.

Ngoài cách gọi trực tiếp bằng tên Function, chúng ta cũng có thể lấy địa chỉ của Function bằng toán tử &. 

&say_hello

Biểu thức trên biểu diễn địa chỉ của Function say_hello. Trong hầu hết biểu thức, tên Function cũng tự động được chuyển đổi thành Pointer đến Function tương ứng. 

say_hello
&say_hello

Hai biểu thức trên đều có thể được sử dụng để khởi tạo một Function Pointer phù hợp.

1.2. Function Pointer là gì?

Function Pointer là một Pointer có khả năng lưu địa chỉ của một Function có kiểu trả về và danh sách tham số tương thích với kiểu Pointer đó.

Khác với Data Pointer, Function Pointer không trỏ đến dữ liệu mà trỏ đến một Function có thể được gọi thông qua Pointer.

Ví dụ, xét Function: 

int add(int a, int b)
{
    return a + b;
}

Function này có các đặc điểm:

  • Kiểu trả về: int.
  • Số lượng tham số: 2.
  • Kiểu tham số: int và int.
  • Tên Function: add.

Một Function Pointer tương ứng có thể được khai báo như sau: 

int (*operation)(int, int);

Điều này có nghĩa operation là một Pointer trỏ đến Function có hai tham số kiểu int và trả về giá trị kiểu int.

1.3. Cú pháp khai báo Function Pointer

Cú pháp tổng quát:

return_type (*pointer_name)(parameter_types);

Trong đó:

  • return_type: Kiểu dữ liệu mà Function trả về.
  • pointer_name: Tên Function Pointer.
  • parameter_types: Danh sách kiểu dữ liệu của các tham số Function.
  • (*pointer_name): Dấu ngoặc đơn xác định Pointer trỏ đến Function.

Một số ví dụ:

Khai báo Ý nghĩa
void (*ptr)(void); Pointer đến Function không có tham số và không trả về giá trị.
int (*ptr)(int); Pointer đến Function nhận một int và trả về int.
float (*ptr)(float, float); Pointer đến Function nhận hai float và trả về float.
uint8_t (*ptr)(uint8_t); Pointer đến Function nhận một uint8_t và trả về uint8_t.
Điểm cần nhớ: Dấu ngoặc đơn trong int (*ptr)(int, int) rất quan trọng. Nếu bỏ dấu ngoặc, khai báo sẽ mang ý nghĩa khác.

2. Khai báo và sử dụng Function Pointer

2.1. Khởi tạo Function Pointer

Sau khi khai báo Function Pointer, chúng ta có thể gán địa chỉ của một Function có kiểu tương thích cho Pointer đó. 

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int (*operation)(int, int);

    operation = add;

    printf("Result: %d\n", operation(10, 20));

    return 0;
}

Kết quả:

Result: 30

Giải thích:

  • add() là Function nhận hai tham số kiểu int.
  • operation là Function Pointer tương thích với add().
  • operation = add; gán địa chỉ Function add cho Pointer.
  • operation(10, 20) gọi Function thông qua Pointer.

2.2. Khởi tạo Function Pointer ngay khi khai báo

Thay vì khai báo Function Pointer trước rồi mới gán địa chỉ, chúng ta có thể khởi tạo trực tiếp: 

#include <stdio.h>

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    int (*operation)(int, int) = multiply;

    int result = operation(5, 4);

    printf("Result: %d\n", result);

    return 0;
}

Kết quả:

Result: 20

Cách khai báo này giúp đảm bảo Function Pointer được khởi tạo trước khi sử dụng.

2.3. Gọi Function thông qua Function Pointer

Có hai cách phổ biến để gọi Function thông qua Function Pointer. 

operation(10, 20);

(*operation)(10, 20);

Cả hai cách trên đều thực hiện việc gọi Function mà operation đang trỏ đến.

Ví dụ:

#include <stdio.h>

int subtract(int a, int b)
{
    return a - b;
}

int main(void)
{
    int (*operation)(int, int) = subtract;

    printf("Method 1: %d\n", operation(20, 5));

    printf("Method 2: %d\n", (*operation)(20, 5));

    return 0;
}

Kết quả:

Method 1: 15
Method 2: 15

Trong thực tế, cách gọi trực tiếp bằng tên Pointer operation() thường được sử dụng nhiều hơn vì cú pháp ngắn gọn và dễ đọc.

2.4. Thay đổi Function được gọi thông qua Pointer

Một ưu điểm của Function Pointer là chúng ta có thể thay đổi Function mà Pointer đang tham chiếu trong quá trình thực thi chương trình. 

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    int (*operation)(int, int);

    operation = add;
    printf("Addition: %d\n", operation(10, 5));

    operation = subtract;
    printf("Subtraction: %d\n", operation(10, 5));

    operation = multiply;
    printf("Multiplication: %d\n", operation(10, 5));

    return 0;
}

Kết quả:

Addition: 15
Subtraction: 5
Multiplication: 50

Trong ví dụ này, cùng một Function Pointer operation lần lượt trỏ đến ba Function khác nhau.

Điều này cho phép chương trình lựa chọn hành vi cần thực hiện dựa trên điều kiện hoặc trạng thái hiện tại.

3. Function Pointer và Function Declaration

3.1. Phân biệt Function Pointer với Function thông thường

Function thông thường và Function Pointer có mối liên hệ với nhau, nhưng chúng không phải cùng một đối tượng. 

int add(int a, int b);

int (*operation)(int, int);
Đặc điểm Function Function Pointer
Bản chất Định nghĩa một đoạn mã thực thi. Pointer lưu địa chỉ Function.
Khai báo int add(int, int); int (*ptr)(int, int);
Thực hiện lời gọi add(10, 20); ptr(10, 20);
Khả năng thay đổi mục tiêu Tên Function xác định Function cụ thể. Có thể được gán một Function tương thích khác.

3.2. Function Pointer phải có kiểu tương thích

Một Function Pointer chỉ nên được gán địa chỉ của Function có kiểu trả về và danh sách tham số tương thích.

Ví dụ:

int add(int a, int b)
{
    return a + b;
}

float calculate_average(float a, float b)
{
    return (a + b) / 2.0f;
}

int (*operation)(int, int);

operation = add;  /* Compatible */

/* Không tương thích về Function Type */
operation = calculate_average;

Function add() có kiểu trả về int và nhận hai tham số int. Trong khi đó, calculate_average() trả về float và nhận hai tham số float.

Vì vậy, hai Function này không có cùng Function Type. Việc gán một Function cho Function Pointer không tương thích có thể dẫn đến hành vi không xác định khi gọi thông qua Pointer.

Ghi nhớ: Khi sử dụng Function Pointer, cần đảm bảo kiểu trả về, số lượng tham số và kiểu của từng tham số phù hợp với Function được gọi.

4. Callback Function

4.1. Callback Function là gì?

Callback Function là một Function được truyền vào một Function khác thông qua Function Pointer. Function nhận Pointer có thể gọi lại Function được truyền vào khi một điều kiện hoặc sự kiện nhất định xảy ra.

Nói cách khác, thay vì một Function tự quyết định toàn bộ hành vi, nó có thể nhận một Function khác từ bên ngoài để thực hiện một phần công việc.

Callback thường được sử dụng để:

  • Cho phép một Function thực hiện các hành vi khác nhau tùy theo Callback được truyền vào.
  • Tách phần xử lý chung khỏi phần xử lý cụ thể.
  • Thông báo khi một sự kiện hoàn thành.
  • Xây dựng các cơ chế Event Handler hoặc Driver Interface.

4.2. Cách truyền Function Pointer vào Function khác

Xét ví dụ một Function thực hiện phép tính bằng cách nhận một Function Pointer làm tham số. 

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int calculate(int a,
              int b,
              int (*operation)(int, int))
{
    return operation(a, b);
}

int main(void)
{
    int result1 = calculate(20, 10, add);
    int result2 = calculate(20, 10, subtract);

    printf("Addition: %d\n", result1);
    printf("Subtraction: %d\n", result2);

    return 0;
}

Kết quả:

Addition: 30
Subtraction: 10

Giải thích:

  • add() thực hiện phép cộng.
  • subtract() thực hiện phép trừ.
  • calculate() nhận hai số nguyên và một Function Pointer.
  • operation(a, b) gọi Callback được truyền vào.
  • main() quyết định Function nào sẽ được sử dụng.

Trong trường hợp này, add và subtract là hai Callback Function được truyền vào calculate().

4.3. Callback với Function không có giá trị trả về

Callback không bắt buộc phải trả về một giá trị. Chúng ta cũng có thể sử dụng Function Pointer đến Function có kiểu trả về void. 

#include <stdio.h>

void on_success(void)
{
    printf("Operation completed successfully!\n");
}

void on_error(void)
{
    printf("Operation failed!\n");
}

void execute_operation(int status,
                       void (*callback)(void))
{
    printf("Executing operation...\n");

    if (status == 0) {
        callback();
    }
}

int main(void)
{
    execute_operation(0, on_success);
    execute_operation(1, on_error);

    return 0;
}

Kết quả:

Executing operation...
Operation completed successfully!
Executing operation...

Trong ví dụ trên, Callback chỉ được gọi khi điều kiện status == 0 thỏa mãn. Khi điều kiện không thỏa mãn, Function execute_operation() không gọi Callback.

Lưu ý rằng ví dụ này truyền on_error vào lần gọi thứ hai nhưng Function chỉ gọi Callback trong nhánh thành công. Đây là chủ ý để minh họa rằng Function nhận Callback có quyền quyết định thời điểm gọi nó.

4.4. Callback với tham số dữ liệu

Trong thực tế, Callback thường cần nhận dữ liệu từ Function thực hiện lời gọi. Vì vậy, chúng ta có thể khai báo Callback có các tham số cụ thể. 

#include <stdio.h>
#include <stdint.h>

typedef void (*DataCallback)(uint8_t data);

void receive_data_handler(uint8_t data)
{
    printf("Received data: 0x%02X\n",
           (unsigned int)data);
}

void process_received_data(uint8_t data,
                           DataCallback callback)
{
    printf("Processing received data...\n");

    callback(data);
}

int main(void)
{
    process_received_data(0xA5U, receive_data_handler);

    return 0;
}

Kết quả:

Processing received data...
Received data: 0xA5

Trong ví dụ này:

  • DataCallback là một kiểu Function Pointer.
  • receive_data_handler() là Callback nhận một byte dữ liệu.
  • process_received_data() thực hiện xử lý dữ liệu chung.
  • Sau khi xử lý, Function gọi Callback và truyền dữ liệu nhận được.
Điểm quan trọng: Callback cho phép Function xử lý chung không cần biết chi tiết về hành vi cụ thể của Function được gọi lại. Hành vi đó được cung cấp từ bên ngoài thông qua Function Pointer.

5. Typedef với Function Pointer

5.1. Vì sao nên sử dụng typedef?

Khi Function Pointer có nhiều tham số hoặc được sử dụng ở nhiều nơi, khai báo trực tiếp có thể khiến mã nguồn dài và khó đọc.

Ví dụ:

void (*callback)(uint8_t, uint16_t, uint32_t);

Chúng ta có thể sử dụng typedef để tạo một tên kiểu dữ liệu mới cho Function Pointer. 

typedef void (*CallbackType)(uint8_t,
                             uint16_t,
                             uint32_t);

Sau đó, có thể sử dụng CallbackType để khai báo các biến Function Pointer. 

CallbackType callback1;
CallbackType callback2;

Cách này giúp mã nguồn ngắn gọn và dễ quản lý hơn.

5.2. Ví dụ sử dụng typedef với Callback

#include <stdio.h>
#include <stdint.h>

typedef void (*CallbackType)(uint8_t);

void led_on(uint8_t led_id)
{
    printf("LED %u is ON\n",
           (unsigned int)led_id);
}

void led_off(uint8_t led_id)
{
    printf("LED %u is OFF\n",
           (unsigned int)led_id);
}

void control_led(uint8_t led_id,
                 CallbackType callback)
{
    callback(led_id);
}

int main(void)
{
    control_led(1U, led_on);
    control_led(2U, led_off);

    return 0;
}

Kết quả:

LED 1 is ON
LED 2 is OFF

Trong ví dụ này, CallbackType đại diện cho kiểu Function Pointer nhận một tham số uint8_t và không trả về giá trị.

Cả led_on() và led_off() đều có kiểu tương thích với CallbackType, vì vậy chúng có thể được truyền vào control_led().

5.3. Sử dụng typedef trong Function Declaration

typedef cũng giúp đơn giản hóa khai báo tham số của Function. 

typedef int (*OperationCallback)(int, int);

int calculate(int a,
              int b,
              OperationCallback callback);

So với việc viết trực tiếp: 

int calculate(int a,
              int b,
              int (*callback)(int, int));

Cách sử dụng typedef giúp Function Declaration dễ đọc hơn, đặc biệt khi Callback được sử dụng trong nhiều Module.

Trong Embedded C, typedef thường được sử dụng để định nghĩa các Callback Type trong Header File. Nhờ đó, các Module có thể thống nhất kiểu Callback khi giao tiếp với nhau.

6. Array of Function Pointers

6.1. Khái niệm Array of Function Pointers

Tương tự như Array of Data Pointers, chúng ta cũng có thể tạo một Array mà mỗi phần tử là một Function Pointer.

Ví dụ:

int (*operations[3])(int, int);

Khai báo trên có nghĩa:

  • operations là một Array gồm 3 phần tử.
  • Mỗi phần tử là một Function Pointer.
  • Mỗi Function Pointer trỏ đến Function nhận hai tham số int.
  • Function được gọi phải trả về int.

6.2. Khởi tạo Array of Function Pointers

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    int (*operations[3])(int, int) = {
        add,
        subtract,
        multiply
    };

    printf("Add: %d\n", operations[0](10, 5));
    printf("Subtract: %d\n", operations[1](10, 5));
    printf("Multiply: %d\n", operations[2](10, 5));

    return 0;
}

Kết quả:

Add: 15
Subtract: 5
Multiply: 50

Trong ví dụ này, mỗi phần tử của Array lưu địa chỉ của một Function khác nhau. Chúng ta có thể lựa chọn Function cần gọi bằng chỉ số Array.

6.3. Sử dụng Array of Function Pointers với Switch

Array of Function Pointers có thể được sử dụng để thay thế một số cấu trúc điều kiện dài khi chương trình cần lựa chọn giữa nhiều Function có cùng kiểu. 

#include <stdio.h>
#include <stdint.h>

typedef int (*Operation)(int, int);

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int multiply(int a, int b)
{
    return a * b;
}

int main(void)
{
    Operation operations[3] = {
        add,
        subtract,
        multiply
    };

    uint8_t operation_id = 2U;

    if (operation_id < 3U) {
        int result = operations[operation_id](10, 5);

        printf("Result: %d\n", result);
    }

    return 0;
}

Kết quả:

Result: 50

Với operation_id = 2, chương trình gọi Function ở vị trí thứ ba trong Array, tương ứng với multiply().

Trước khi truy cập Array, chương trình cần kiểm tra chỉ số để đảm bảo không truy cập vượt quá giới hạn.

Ứng dụng: Array of Function Pointers có thể được sử dụng để xây dựng Function Table, Command Table hoặc một số cơ chế lựa chọn Handler trong Embedded Software.

7. Ứng dụng Function Pointer và Callback trong Embedded C

7.1. Callback trong Driver Interface

Trong Embedded Systems, các Driver thường cung cấp những Function để các Module khác có thể đăng ký Callback. Khi một sự kiện xảy ra, Driver có thể gọi Callback đã đăng ký.

Ví dụ đơn giản, một Module nhận dữ liệu có thể cho phép Application đăng ký Function xử lý dữ liệu. 

#include <stdio.h>
#include <stdint.h>

typedef void (*RxCallback)(uint8_t data);

static RxCallback rx_callback = NULL;

void register_rx_callback(RxCallback callback)
{
    rx_callback = callback;
}

void uart_receive_simulation(uint8_t data)
{
    printf("UART received data: 0x%02X\n",
           (unsigned int)data);

    if (rx_callback != NULL) {
        rx_callback(data);
    }
}

void application_rx_handler(uint8_t data)
{
    printf("Application processes: 0x%02X\n",
           (unsigned int)data);
}

int main(void)
{
    register_rx_callback(application_rx_handler);

    uart_receive_simulation(0x5AU);

    return 0;
}

Kết quả:

UART received data: 0x5A
Application processes: 0x5A

Giải thích:

  • RxCallback định nghĩa kiểu Function Pointer cho Callback nhận dữ liệu.
  • rx_callback lưu địa chỉ Callback đã đăng ký.
  • register_rx_callback() cho phép Application đăng ký Callback.
  • uart_receive_simulation() mô phỏng quá trình nhận dữ liệu.
  • Nếu Callback hợp lệ, Driver gọi lại Function đã đăng ký.
  • application_rx_handler() thực hiện xử lý dữ liệu ở Application Layer.

Đây là mô hình minh họa cơ bản cho cơ chế Callback giữa Driver Layer và Application Layer.

7.2. Callback trong Timer Event

Một ứng dụng khác của Callback là xử lý sự kiện Timer. Khi Timer đạt đến một điều kiện nhất định, chương trình có thể gọi một Function đã được đăng ký trước đó. 

#include <stdio.h>
#include <stdint.h>

typedef void (*TimerCallback)(void);

static TimerCallback timer_callback = NULL;

void register_timer_callback(TimerCallback callback)
{
    timer_callback = callback;
}

void timer_event(void)
{
    printf("Timer event occurred!\n");

    if (timer_callback != NULL) {
        timer_callback();
    }
}

void led_toggle_handler(void)
{
    printf("LED state toggled!\n");
}

void system_tick_handler(void)
{
    printf("System tick processed!\n");
}

int main(void)
{
    register_timer_callback(led_toggle_handler);

    timer_event();

    register_timer_callback(system_tick_handler);

    timer_event();

    return 0;
}

Kết quả:

Timer event occurred!
LED state toggled!
Timer event occurred!
System tick processed!

Cùng một cơ chế Timer Event nhưng chương trình có thể thực hiện những hành vi khác nhau tùy theo Callback được đăng ký.

Trong hệ thống thực tế, Timer Event có thể được tạo ra bởi Hardware Timer, Software Timer hoặc một Scheduler. Ví dụ trên chỉ mô phỏng việc gọi Callback, không trực tiếp cấu hình Hardware Timer.

7.3. Callback trong Communication Module

Trong các hệ thống giao tiếp như UART, SPI hoặc CAN, một Module có thể cần thông báo cho Application khi dữ liệu đã được nhận hoặc quá trình truyền dữ liệu đã hoàn thành.

Callback có thể được sử dụng để thông báo những sự kiện này. 

#include <stdio.h>
#include <stdint.h>

typedef void (*TxCompleteCallback)(uint8_t status);

void application_tx_complete(uint8_t status)
{
    if (status == 0U) {
        printf("Transmission completed successfully.\n");
    } else {
        printf("Transmission failed.\n");
    }
}

void communication_transmit(
    const uint8_t *data,
    uint8_t length,
    TxCompleteCallback callback)
{
    if ((data == NULL) || (length == 0U)) {
        if (callback != NULL) {
            callback(1U);
        }

        return;
    }

    printf("Transmitting %u bytes...\n",
           (unsigned int)length);

    /*
     * Mô phỏng quá trình truyền dữ liệu.
     * Không thực hiện truyền Hardware thực tế.
     */

    if (callback != NULL) {
        callback(0U);
    }
}

int main(void)
{
    uint8_t tx_buffer[3] = {
        0x11U, 0x22U, 0x33U
    };

    communication_transmit(
        tx_buffer,
        3U,
        application_tx_complete
    );

    return 0;
}

Kết quả:

Transmitting 3 bytes...
Transmission completed successfully.

Trong ví dụ này:

  • communication_transmit() đại diện cho một Function truyền dữ liệu.
  • TxCompleteCallback là kiểu Function Pointer dùng để thông báo kết quả.
  • application_tx_complete() xử lý kết quả ở Application Layer.
  • Callback được gọi khi quá trình mô phỏng truyền dữ liệu kết thúc.

Trong Driver thực tế, Callback hoàn thành truyền dữ liệu thường được gọi khi Hardware hoặc Driver xác nhận quá trình truyền đã hoàn tất.

Lưu ý trong Embedded Systems: Không phải mọi Callback đều được gọi trong cùng một ngữ cảnh thực thi. Một số Callback có thể được gọi từ Interrupt Service Routine (ISR), trong khi một số khác được gọi từ Main Loop hoặc Task. Điều này cần được xem xét khi thiết kế chương trình thực tế.

8. Những lỗi thường gặp khi sử dụng Function Pointer

8.1. Gọi Function Pointer chưa được khởi tạo

Function Pointer là một Pointer, vì vậy cần được khởi tạo trước khi sử dụng. 

void (*callback)(void);

callback();

Trong ví dụ trên, callback chưa được gán địa chỉ của một Function hợp lệ. Việc gọi Function thông qua Pointer này dẫn đến hành vi không xác định.

Cách khởi tạo an toàn hơn:

void (*callback)(void) = NULL;

if (callback != NULL) {
    callback();
}

8.2. Gán Function không tương thích kiểu

Function Pointer phải có kiểu tương thích với Function được gán. 

void handler_a(int value)
{
    /* Processing */
}

void handler_b(float value)
{
    /* Processing */
}

void (*callback)(int);

callback = handler_a;

/* Không tương thích */
callback = handler_b;

handler_a() nhận một tham số int, trong khi handler_b() nhận một tham số float. Vì vậy, chỉ handler_a() có kiểu phù hợp với Function Pointer đã khai báo.

8.3. Nhầm lẫn giữa Function Pointer và Data Pointer

Function Pointer và Data Pointer đều là Pointer, nhưng chúng tham chiếu đến những loại đối tượng khác nhau. 

int value = 10;

int *data_ptr = &value;

int add(int a, int b)
{
    return a + b;
}

int (*function_ptr)(int, int) = add;

Trong ví dụ này:

  • data_ptr trỏ đến một biến dữ liệu kiểu int.
  • function_ptr trỏ đến Function add().

Không nên xem Function Pointer và Data Pointer là hai kiểu có thể thay thế tùy ý cho nhau. C cũng không đảm bảo rằng chúng có cùng kích thước hoặc cùng cách biểu diễn trên mọi nền tảng.

8.4. Quên kiểm tra Callback trước khi gọi

Khi thiết kế cơ chế đăng ký Callback, cần kiểm tra Pointer trước khi gọi để tránh sử dụng một Callback chưa được đăng ký. 

typedef void (*CallbackType)(void);

static CallbackType callback = NULL;

void execute_callback(void)
{
    if (callback != NULL) {
        callback();
    }
}

Việc kiểm tra này giúp Function có thể xử lý trường hợp chưa có Callback được đăng ký.

8.5. Truyền Callback có tham số không phù hợp

Khi truyền Callback vào một Function, cần đảm bảo kiểu tham số của Callback tương thích với kiểu mà Function nhận và sử dụng. 

typedef void (*DataCallback)(uint8_t);

void process_data(DataCallback callback)
{
    callback(10U);
}

void valid_handler(uint8_t data)
{
    printf("%u\n", (unsigned int)data);
}

void invalid_handler(uint16_t data)
{
    printf("%u\n", (unsigned int)data);
}

valid_handler() có kiểu phù hợp với DataCallback. Không nên truyền một Function có kiểu không tương thích và dựa vào việc Compiler có thể chấp nhận một phép chuyển đổi Pointer để xem đó là cách gọi hợp lệ.

Ghi nhớ: Khi làm việc với Callback, cần chú ý ba vấn đề chính: Function Pointer phải được khởi tạo hợp lệ, kiểu Function phải tương thích và Callback cần được gọi đúng thời điểm.

9. So sánh Function Pointer và Callback Function

Function Pointer và Callback Function có mối liên hệ chặt chẽ, nhưng hai khái niệm này mô tả những khía cạnh khác nhau.

Tiêu chí Function Pointer Callback Function
Khái niệm Pointer lưu địa chỉ của Function. Function được truyền vào Function khác để được gọi lại.
Vai trò Cơ chế tham chiếu và gọi Function. Cơ chế cung cấp hành vi cho Function khác.
Cách sử dụng Có thể gọi Function thông qua Pointer. Thường được truyền qua tham số Function Pointer.
Phạm vi ứng dụng Function Table, lựa chọn Function, Callback. Event Handler, Driver Notification, Timer Event.
Mối quan hệ Là cơ chế thường được dùng để triển khai Callback. Là một cách sử dụng Function Pointer.
Điểm cần nhớ: Function Pointer là cơ chế của ngôn ngữ C. Callback Function là một kỹ thuật lập trình sử dụng cơ chế đó để cho phép một Function gọi lại Function khác.

10. Những khái niệm cần nhớ

Khái niệm Ý nghĩa
Function Pointer Pointer lưu địa chỉ của một Function có kiểu tương thích.
Function Type Kiểu Function được xác định bởi kiểu trả về và danh sách tham số.
Function Call Thực hiện lời gọi Function thông qua tên Function hoặc Function Pointer.
Callback Function Function được truyền vào Function khác để Function đó có thể gọi lại.
typedef Function Pointer Tạo tên kiểu dữ liệu mới cho một loại Function Pointer.
Array of Function Pointers Array chứa nhiều Function Pointer có cùng kiểu tương thích.
Event Handler Function xử lý một sự kiện cụ thể, thường có thể được đăng ký làm Callback.
Driver Callback Callback được Driver gọi để thông báo một sự kiện hoặc kết quả xử lý.

Tóm tắt

Function Pointer là một Pointer có khả năng lưu địa chỉ của Function. Nó cho phép chương trình gọi Function thông qua Pointer thay vì chỉ gọi trực tiếp bằng tên Function.

Cú pháp khai báo cơ bản: 
return_type (*pointer_name)(parameter_types);
Ví dụ: 
int (*operation)(int, int);
Function Pointer có thể được khởi tạo bằng địa chỉ của Function có kiểu tương thích và được sử dụng để gọi Function thông qua Pointer.

Callback Function là một kỹ thuật sử dụng Function Pointer để truyền một Function vào Function khác. Function nhận Callback có thể gọi lại Function được truyền vào khi một điều kiện hoặc sự kiện xảy ra.

typedef giúp đơn giản hóa việc khai báo Function Pointer, đặc biệt khi Callback được sử dụng trong nhiều Module. Ngoài ra, Array of Function Pointers cho phép tổ chức nhiều Function có cùng kiểu trong một cấu trúc Array để lựa chọn và gọi theo chỉ số.

Trong Embedded C, Function Pointer và Callback thường xuất hiện trong Driver Interface, Timer Callback, Communication Module và Event Handler. Việc sử dụng đúng cách giúp tăng tính linh hoạt và khả năng mở rộng của chương trình.
